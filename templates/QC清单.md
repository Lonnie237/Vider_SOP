# QC 清单 · <项目名>

> 交付前逐项打勾；任何一项不过，不发布。建议同时跑 `ffprobe` 自动核对规格。

## 1. 规格

- [ ] 分辨率 / 帧率 / 画幅与交付规格一致
- [ ] 编码 / 封装 / 码率在平台推荐区间
- [ ] 音频采样率 / 声道 / 响度达标
- [ ] 文件命名符合规范，版本号正确
- [ ] 文件大小在平台限制内

自动核对：

```bash
ffprobe -v error -show_entries format=duration,size,bit_rate \
  -show_entries stream=codec_name,width,height,r_frame_rate,sample_rate,channels \
  -of json output.mp4
```

## 2. 画面

- [ ] 无黑帧 / 花屏 / 掉帧
- [ ] 无水印 / 无未授权素材 / 无隐私信息
- [ ] 字幕不挡脸、不出安全区、无错别字
- [ ] 转场 / 特效无明显跳变
- [ ] 调色统一，无偏色

## 3. 声音

- [ ] 无爆音 / 底噪 / 电流声
- [ ] 人声清晰，音乐不压人声（对白优先）
- [ ] 音画同步（口型 / 动作 / 卡点）
- [ ] 首尾无突兀截断，淡入淡出合理

## 4. 内容

- [ ] 前 3 秒钩子成立
- [ ] 信息与脚本一致，无事实错误
- [ ] CTA 明确
- [ ] 封面 / 标题 / 简介就绪
- [ ] 平台合规（敏感词、版权、广告标识）

## 5. 发布

- [ ] 在目标机型 / 平台预览过（手机竖屏必看）
- [ ] 上传后播放正常（非仅本地预览）
- [ ] 发布信息（标题 / 话题 / 时间）确认
