## 3. 导出命令（FFmpeg 参考）

```bash
# 横屏 1080p30 H.264 + AAC，两遍 VBR 示例（按需改码率）
ffmpeg -i input.mp4 \
  -c:v libx264 -preset slow -crf 18 -profile:v high -level 4.1 \
  -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 192k -ar 48000 -ac 2 \
  -movflags +faststart output.mp4
```
