# research/ · 调研笔记

> 结论进 `knowledge/`，过程留在这里。**没有来源的结论不进知识库**。

## 调研规范

1. 先写问题清单（要确认什么、什么情况下算确认）。
2. 来源优先级：官方文档 / 仓库 README / release notes > 官方博客 > 高质量第三方 > 个人博客。
3. 记录：URL、访问日期、关键原文（不超过 100 字）、你的判断（`[事实]` / `[推断]` / `[待确认]`）。
4. 结论落到知识条目时，在条目「来源」节引用本笔记编号。
5. 易变数据（star 数、版本、价格、平台规则）必须带日期，禁止写“目前 / 最新”。

## 笔记命名

`YYYY-MM-DD-<主题>.md`，如 `2026-11-03-开源视频编辑生态.md`。
