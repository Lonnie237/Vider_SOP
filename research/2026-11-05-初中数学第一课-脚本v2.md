## 2. 范围收缩（v1 → v2 的关键修改）

v1 把「相反数、绝对值、-a」也塞进第一课，超出七上第一章起始课的实际顺序。v2 收缩为：

- **正式讲**：1.1 正数和负数 + 1.2.2 数轴初步；
- **只预告**：相反数、绝对值、有理数运算（片尾一句，不设目标/测验）；
- **删除**：「-a 不一定是负数」——学生还没学字母表示数，放到后续课时；
- **保留**：数轴比较（用“右 > 左”，不引入绝对值法则）。

> 这是 v2 最重要的质量改进：**第一课不贪多，把「负数为什么存在 + 0 的分界 + 数轴」讲透。**

## 4. 概念图

小学数（自然数/分数/小数）
→ 相反意义的量
→ 正数 / 负数 / 0（0 是分界）
→ 数轴（原点、正方向、单位长度）
→ 用数轴表示与比较大小
→ 下一课：相反数 / 绝对值 / 有理数运算

边界：本课不要求「有理数分类」「绝对值计算」「负数运算」。

## 5. 误区表

| 误区 | 错误说法 | 为什么错 | 正确说法 | 纠正例子 |
|---|---|---|---|---|
| M1 | 0 就是“没有” | 0 是数，是正负分界；0℃ 是确定温度 | 0 既不是正数也不是负数 | 0℃ 是水的冰点（标准大气压） |
| M2 | 负号就是减号 | 负号可表示数的性质/方向；减号是运算 | 写在数前是负号，写在两数之间是减号 | -3 是负数；3-5 是减法 |
| M3 | 负数比较，数字大的更大 | 数轴上越往左越小 | 两个负数，越靠左越小 | -3 < -1，虽然 3 > 1 |
| M4 | 0℃ 就是没有温度 | 0℃ 是温标上的一个确定点 | 0℃ 不是“没有温度” | 冰水混合物在标准大气压下约 0℃ |
| M5 | 正数一定比负数“大很多” | 大小关系看数轴位置 | 正数 > 0 > 负数 | -100 < 1 |

## 6. 证据（后测 5 题 + 答案）

1. 判断：-5、0、+3、-0.5 中，哪些是正数？哪些是负数？0 是什么？
   - 答案：+3 正数；-5、-0.5 负数；0 既不是正数也不是负数。
2. 用正负数表示（先定基准）：
   - 零上 8℃ / 零下 8℃；收入 200 元 / 支出 150 元；海平面以上 30 米 / 以下 10 米。
   - 答案：+8℃ / -8℃；+200 / -150；+30 / -10（基准分别为 0℃、收支平衡、海平面）。
3. 解释：为什么说「0℃ 不是没有温度」？0 在正负数里是什么角色？
   - 答案：0℃ 是标准大气压下水的冰点，是一个确定温度；0 是正负数的分界，既不是正数也不是负数。
4. 数轴：把 -3、-1、0、2 画在数轴上，并比较 -3 与 -1、0 与 2 的大小。
   - 答案：位置正确；-3 < -1；0 < 2。
5. 应用：电梯从 -2 层到 3 层，一共经过几层？用数轴说明。
   - 答案：5 层（-2 → -1 → 0 → 1 → 2 → 3，共 5 个间隔；不要求列减法算式）。
