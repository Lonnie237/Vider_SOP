# 初中数学第一课 · 负数与数轴（方向与脚本 v1）

- 日期：2026-11-05
- 状态：方向已选；**v2 已按 SOP 补齐目标/证据/概念图**，见 [脚本 v2](2026-11-05-初中数学第一课-脚本v2.md)
- 选题：初中数学第一课
- 选定方向：**以人教版（2024）七年级上册 1.1「正数和负数」为锚点，讲清「负数为什么存在、是什么、数轴怎么用」**
- 目标时长：5–6 分钟（16:9），可裁 90 秒预告版

## 1. 为什么选这个方向

「初中数学第一课」有几种做法：

| 方向 | 问题 |
|---|---|
| 泛讲「初中数学怎么学」 | 容易空泛，变成鸡汤/方法口号 |
| 从「算术到代数」总论 | 太抽象，初一新生没有具体抓手 |
| 直接讲「有理数」全章 | 内容太多，第一课装不下 |
| **讲 1.1 正数和负数 + 数轴** | **具体、教材有锚点、能回答「为什么学」** |

选定逻辑：第一课不应该先背定义，而应该先解决一个真实困惑——**零下 3℃ 为什么写成 -3℃？0℃ 是没有温度吗？** 从这个困惑出发，引出负数、0 的分界、数轴、相反数与绝对值。

## 2. 受众与目标

- 受众：初一新生（七年级上册），以及想帮孩子过渡的家长。
- 前置知识：小学的自然数、分数、小数；会画直线、会比较正数大小。
- 看完能回答：
  1. 为什么需要负数？
  2. 0 为什么既不是正数也不是负数？
  3. 数轴的三要素是什么？怎么用数轴比较大小？
  4. 相反数和绝对值分别在说什么？
- 不追求：有理数运算、乘方、科学记数法（后续课时）。

## 3. 调研结论（先事实，后脚本）

### 3.1 课标要求

《义务教育数学课程标准（2022 年版）》在 7–9 年级「数与代数」中要求：

- 理解负数的意义；
- 理解有理数的意义，能用数轴上的点表示有理数，能比较有理数的大小；
- 借助数轴理解相反数和绝对值的意义，掌握求有理数的相反数与绝对值的方法，知道 |a| 的含义（a 表示有理数）。

> 来源：教育部《义务教育数学课程标准（2022 年版）》，2022-04-20 发布；通知页：http://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html

### 3.2 教材位置（人教版 2024 七上）

第一章 有理数：

- 1.1 正数和负数
- 1.2 有理数及其大小比较
  - 1.2.1 有理数的概念
  - 1.2.2 数轴
  - 1.2.3 相反数
  - 1.2.4 绝对值
  - 1.2.5 有理数的大小比较

> 来源：人教版（2024）数学七年级上册目录（学科网电子课本页，2024-10-17）：https://www.zxxk.com/ebook/detail-1017757.html

### 3.3 关键定义（按教材口径）

- **正数**：大于 0 的数；**负数**：在正数前面加上“-”的数；**0 既不是正数，也不是负数**。
- **相反意义的量**：零上/零下、收入/支出、增加/减少、向东/向西等；可以用正负数表示。
- **数轴**：规定了原点、正方向、单位长度的直线；原点、正方向、单位长度是数轴三要素。
- **相反数**：只有符号不同的两个数（0 的相反数是 0）；在数轴上关于原点对称。
- **绝对值**：数轴上表示数 a 的点与原点的距离，记作 |a|；|a| ≥ 0。
- **有理数**：整数和分数统称有理数；0 是有理数。

### 3.4 历史锚点（可选，30 秒）

- 《九章算术》（约公元 1 世纪）中的「正负术」给出了正负数加减法则，是中国数学史上很早的系统记载。
- 刘徽用红色、黑色算筹区分正负数（“正算赤，负算黑”）。
- 讲历史只为说明「负数不是突然冒出来的规则」，不展开欧洲数学史。

> 来源：科普中国《正负数的由来》，2018-06-25：https://cloud.kepuchina.cn/newSearch/imgText?from=1&id=6969021617216421888&is_self=2

### 3.5 学生常见误区（脚本要正面处理）

| 误区 | 正确说法 |
|---|---|
| 0 就是“没有” | 0 是数，是正负数的分界；0℃ 不是没有温度 |
| -a 一定是负数 | 不一定；a 是负数时，-a 是正数 |
| 负号就是减号 | 负号是符号，减号是运算；要看位置和语境 |
| 绝对值等于本身 | 只有非负数（正数和 0）的绝对值等于本身 |
| 两个负数比较，绝对值大的更大 | 两个负数，绝对值大的反而小 |

## 4. 视频脚本（5–6 分钟）

> 旁白为口播稿；屏显只保留关键词、数字和关系，不逐字复述旁白。字幕单行、静态，不做逐词高亮。

### S0 封面（0:00–0:06）

- 画面：深色底 + 大标题「初中数学第一课：负数不是‘负’」+ 副标题「从温度到数轴」。
- 屏显：初中数学第一课 / 负数不是“负” / 从温度到数轴。
- 旁白：无。

### S1 开场问题（0:06–0:40）

- 旁白：先问你一个问题：天气预报说，明天最低气温 -3℃。这个“-3”，为什么不能写成“零下 3℃”就完了？还有，0℃ 是没有温度吗？
- 画面：左侧温度计从 3℃ 降到 -3℃；右侧“0℃”放大；问题标题。
- 屏显：-3℃ ≠ 没有温度 / 0℃ 是什么？
- 版式：全屏标题 + 单卡；先给问题，不先给定义。

### S2 为什么要有负数（0:40–1:50）

- 旁白：生活里到处都是“相反意义的量”。零上 3℃ 和零下 3℃，收入 100 元和支出 100 元，海平面以上 20 米和以下 20 米。如果只用正数，你就得每次写“零下”“支出”“以下”，数学就没法统一计算。于是人们约定：先选一个基准，基准以上记正，基准以下记负。
- 画面：三组左右对照（温度、收支、海拔），每组一张卡；基准线居中；左右卡片随旁白出现。
- 屏显：相反意义的量 / 先定基准 / 正负号表示方向
- 版式：三行对比列表；锚点揭示，但结构先在场。

### S3 正数、负数与 0（1:50–2:50）

- 旁白：于是就有了正数和负数。大于 0 的数叫正数，在正数前面加“-”的数叫负数。注意，0 既不是正数，也不是负数——它是正负数的分界。0℃ 不是“没有温度”，0 元也不是“没有钱”，0 是一个确定的数。
- 画面：数轴雏形出现，0 在中间；正数向右，负数向左；0 放大，标注“分界”。
- 屏显：正数 > 0；负数 < 0；0 是分界
- 版式：中心公式 + 数轴；0 是唯一焦点。

### S4 数轴：把数变成位置（2:50–4:00）

- 旁白：怎么把“相反”看得见？用数轴。画一条直线，规定原点、正方向、单位长度，这就成了数轴。每个有理数都能在数轴上找到自己的位置：+3 在原点右边 3 个单位，-3 在左边 3 个单位。数轴右边的数总比左边大，所以 -3 < -1 < 0 < 2。
- 画面：一条横贯画面的数轴；先画三要素，再放点；+3 与 -3 对称出现；比较大小用高亮区间。
- 屏显：数轴三要素：原点 / 正方向 / 单位长度；右 > 左
- 版式：全宽时间线/数轴；先结构后点；这是全片的主视觉。

### S5 相反数与绝对值（4:00–5:00）

- 旁白：数轴上，+3 和 -3 到原点的距离一样，方向相反，它们互为相反数。0 的相反数还是 0。那距离怎么表示？用绝对值。|3| = 3，|-3| = 3，因为绝对值就是“到原点的距离”，距离不可能是负的。
- 画面：+3/-3 关于原点对称；两条距离括号同时出现；|a| 公式。
- 屏显：相反数：关于原点对称 / 绝对值：到原点的距离 / |a| ≥ 0
- 版式：对称双点 + 距离标注；运动只做“对称展开”。

### S6 比较与易错点（5:00–5:50）

- 旁白：最后记住三句话：正数大于 0，0 大于负数；数轴上右边的大；两个负数比较，绝对值大的反而小。比如 -5 和 -2，|-5| 更大，但 -5 更小。还有，-a 不一定是负数，要看 a 是什么。
- 画面：三行结论卡；一个“-5 vs -2”小对比；一个“-a”反例卡。
- 屏显：右 > 左 / 两个负数：绝对值大反而小 / -a 不一定是负数
- 版式：清单 + 对比；一行一个结论。

### S7 收尾与挑战（5:50–6:10）

- 旁白：第一课先记住三个工具：基准、数轴、符号。下一课，我们会用它们做有理数的加减法。留个问题：如果气温从 -3℃ 升到 2℃，一共升了多少度？
- 画面：三个关键词收束；最后抛出问题；结束卡。
- 屏显：基准 / 数轴 / 符号；-3℃ → 2℃，升了多少度？
- 版式：三卡收尾 + 提问 CTA；HOLD 2 秒。
