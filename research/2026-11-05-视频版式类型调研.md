# 视频版式类型调研（2026-11-05）

- 背景：同一支片里，S1/S2 适合「先给结构」，S3 适合「按词逐项揭示」；用户提出「不同版面处理方式不一样」，需要系统梳理常用版式。
- 结论：**先按「叙事任务」选版式，再按「元素数量/信息密度」决定揭示方式**；常用约 18 种，可归为 5 族 + 8 种叙事语法。

## 2. 三层模型

1. **叙事语法（8）**：flow / decision / terminal / compare / stat / checklist / quote / meter。
2. **版面结构（18）**：见知识点总表。
3. **画幅适配**：16:9 与 9:16 不缩放，重新排安全区与字号。

## 3. 选择规则

- 先定「这一镜要让观众带走什么结论」，再选结构。
- 元素 ≤3：可一次给全；4–6：逐项揭示；>6：拆镜或分组。
- 开场/定义/标题：先给结构，再靠词级高亮带节奏。
- 长列表/对比：先给容器与表头，内容按锚点词逐项揭示。
- 两个元素互相抢：拆成两镜，或明确主次。
- 一镜只一个焦点；一屏只一个主信息。
