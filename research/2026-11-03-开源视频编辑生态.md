# 开源视频编辑生态 调研笔记

- 调研人：lib-scout
- 目标：为「视频制作知识 + SOP 仓库」确定开源工具底座——哪些工具能覆盖 S3–S10、许可证是否可用、维护是否可靠、在本机（macOS / Apple M5 / Python 3.9.6 / Node 26）能否落地。

## 判断标准

- 「许可证确认」= 官方 license 页或仓库 LICENSE 明示，并能说明适用部分（如 FFmpeg 的 LGPL/GPL 分界）。
- 「维护状态确认」= 取得最近 release 标签与发布日期，或仓库最近提交时间（GitHub API 的 `pushed_at`）。
- 「本机可装」= PyPI 存在对应 CPython 版本 + 平台 wheel，或官方提供本平台二进制。
- 「能力确认」= 官方文档明示该能力，或有本机实测记录；仅社区传闻不算。

## 问题清单


1. 8 个核心工具各自的 license、仓库、主语言、平台、最近 release 是什么？

3. 哪些环节只能靠 NLE 或商业软件，开源工具只能做 ◐？

## 方法与过程

1. 用 GitHub REST API 取每个仓库的 `license`、`pushed_at` 与 `releases/latest`，作为维护状态的原始依据。
2. 用 PyPI JSON API 取 `requires_python` 与 wheel 文件名，判断本机 Python 3.9 能否安装。
3. 用 npm registry 取 Editly 的发布版本，与 GitHub release 对比，发现「npm 0.14.2 vs GitHub rc 0.15」的版本分裂。
4. 用官方文档核对许可证、安装方式与 API（FFmpeg legal / Blender license / Remotion license / OTIO adapters）。
5. 本机执行 `ffmpeg` / `python3` / `node` 版本探测，确认能力边界（无 libass、无 moviepy/av）。

复现命令（macOS 自带 curl + python3）：

```bash
curl -s https://api.github.com/repos/remotion-dev/remotion/releases/latest | python3 -c "import json,sys; print(json.load(sys.stdin)['tag_name'])"
curl -s https://pypi.org/pypi/opentimelineio/json | python3 -c "import json,sys; d=json.load(sys.stdin); print(d['info']['version'], d['info']['requires_python'])"
curl -s https://registry.npmjs.org/editly/latest | python3 -c "import json,sys; print(json.load(sys.stdin)['version'])"
ffmpeg -hide_banner -h filter=subtitles 2>&1 | head -1
```

## 结论


- [事实] FFmpeg 9.0.2 为当前发布线（9.0.2 tarball 时间戳 2026-09-19）；核心 LGPL-2.1-or-later，启用 `--enable-gpl` 的构建整体适用 GPL-2.0-or-later。
- [事实] MoviePy 2.2.1（2025-05-21，MIT，requires-python≥3.9）是本机 3.9 可装的最新版；v2 为破坏性升级。
- [事实] PyAV 19.0.2（BSD-3-Clause）要求 Python ≥3.12；15.1.0 是最后支持 3.9 的版本线，且有 cp39 macOS arm64 wheel。
- [事实] Auto-Editor 已用 Nim 重写、CLI 停止经 pip 发布（PyPI 停在 29.3.1），GitHub 最新 31.8.0。
- [事实] OpenTimelineIO 0.18.1（Apache-2.0）内置适配器只有 `otio_json` / `otiod` / `otioz`，其余格式需插件。
- [事实] Remotion 4.0.540 活跃，但采用非 OSI 的 Remotion License：个人与 ≤3 人公司免费，4 人及以上需 Company License。
- [事实] Editly 维护不活跃：npm 稳定版 0.14.2，GitHub 仍为 rc（2025-01-19），最后提交 2025-05-12。
- [事实] Blender 5.2.3 LTS（2026-10-22）为当前稳定版，源码默认 GPL v2+；5.3 预计 2026-11-10 发布并原生支持 OTIO。
- [事实] 生态侧版本：GStreamer 1.28.8、MLT 7.42.0、PySceneDetect 0.7.2、Manim 0.22.1、WhisperX 3.8.6、libass 0.17.5、VapourSynth R82；Demucs 仓库已归档（最后提交 2024-04-24）。
- [推断] 本机 Python 3.9.6 是选型硬约束：PyAV 必须 pin 15.1.0，OTIO 可用 cp39 wheel，MoviePy 可直接装。
- [推断] 本机 FFmpeg 缺 libass/freetype，字幕类流程必须走 Pillow overlay 或另装构建——这会影响口播/教程 SOP 的实现方式。
