# 数学讲解 60–90 秒蓝图：-3 为什么比 -1 小

- 日期：2026-11-11
- 状态：**纸面蓝图，不写代码、不渲染**
- 依据：[数学视频诊断](2026-11-11-数学视频诊断.md)
- 目标：用一个 85–90 秒段落验证「场景优先 + 视觉承载推理」是否成立
- 范围：只做 3 个 Scene + 1 个收束，不做完整课

## 1. 选题与目标

- 概念：负数比较大小（-3 < -1）。
- 受众：初一，已见过负数、知道 0 是分界。
- 核心问题：为什么 -3 比 -1 小？不是“背规则”，而是“看位置”。
- 看完能做什么：能用自己的话解释 -3 < -1；能做 -5 与 -2 的迁移。
- 不做什么：不讲绝对值、不讲运算、不塞完整课。

## 2. 视觉锚点

只用 **一条线**：

- 开场是一支温度计，-1 和 -3 两个标记；
- 温度计的刻度“抽出来”，变成水平数轴；
- 后面所有比较都在这条线上完成，不换卡片。

这是本段的“连续视觉锚点”：观众看到的是同一个对象在变形，而不是每镜换一张 PPT。

## 3. 场景契约

### S1 · 现象/预测（0–15s）

| 字段 | 内容 |
|---|---|
| 学习任务 | 激活直觉，先猜 |
| 视觉锚点 | 一支温度计，两个标记：-1℃、-3℃ |
| 变化 | 两个标记依次亮起；问题出现；停 2 秒 |
| 观众动作 | 心里选一个：哪个更冷？ |
| 证据 | 能说出自己的猜测（不判对错） |
| 禁止 | 不写定义、不出卡片、不提前给答案 |

旁白：先别算，先猜：-3℃ 和 -1℃，哪个温度更低？

### S2 · 视觉模型（15–48s）

| 字段 | 内容 |
|---|---|
| 学习任务 | 把温度变成数轴，看见“左=小” |
| 视觉锚点 | 温度计刻度滑出，接成水平数轴 |
| 变化 | 画 0 → 放 -1 → 放 -3 → 画距离括号 → 出不等号 |
| 观众动作 | 看 -3 在 -1 的哪一边 |
| 证据 | 能指着线说“-3 在左边，所以更小” |
| 禁止 | 不出现“因为负号后数字大”这种未解释的规则；不换版式 |

旁白：把温度放到同一条数轴上。先画 0；-1 在 0 左边 1 格，-3 在左边 3 格。数轴上越往左，数越小。所以 -3 在 -1 左边，-3 小于 -1。

### S3 · 迁移/验证（48–78s）

| 字段 | 内容 |
|---|---|
| 学习任务 | 用同一模型判断新数对 |
| 视觉锚点 | 同一条线向左延伸 |
| 变化 | 出现 -5、-2；先只给点，不给答案；停 2 秒；再落不等号；最后浮出规则注解 |
| 观众动作 | 先猜 -5 和 -2 谁小 |
| 证据 | 能答 -5 < -2，并说“-5 更靠左” |
| 禁止 | 不引入绝对值；不把规则做成新卡片 |

旁白：再试一个：-5 和 -2，谁小？先猜。负 5 在负 2 左边，所以 -5 小于 -2。不看数轴时，负号后面的数越大，位置越靠左，值反而越小。

### S4 · 收束（78–88s）

| 字段 | 内容 |
|---|---|
| 学习任务 | 用一句话锁住方法 |
| 视觉锚点 | 整条线保留，-5 到 +3 都在 |
| 变化 | 只高亮“左/右”与两个关键点，不再加新信息 |
| 观众动作 | 复述 |
| 证据 | 能说“负数比大小，看位置，不看数字大小” |
| 禁止 | 不引入新例子、不做 CTA 卡片 |

旁白：记住：负数比大小，看位置，不看数字大小。

## 4. 纸面分镜（6 格）

第 1 格 · 问题
    温度计
      -1℃  ●
      -3℃  ●
    先猜：哪个更冷？

第 2 格 · 抽出数轴
    温度计刻度  →  0 ─ -1 ─ -3 →
    一条线，不换卡

第 3 格 · 放点
    0 ─── -1 ─── -3 →
         1格      3格
    左 = 小

第 4 格 · 给出关系
    -3 在 -1 左边
    -3 < -1
    括号/距离标注

第 5 格 · 迁移
    -5 ─ -3 ─ -2 ─ -1 ─ 0 →
    先猜：-5 和 -2 谁小？
    停 2 秒

第 6 格 · 收束
    -5 ─ -3 ─ -2 ─ -1 ─ 0 ─ +3 →
    “看位置，不看数字大小”

## 6. 制作约束

- 画幅：1920×1080 / 30fps / 16:9；时长 85–90s。
- 引擎：**只用 Remotion + SVG**，不接 Onda、不接 Manim、不加章节卡。
- 视觉：保留现有黑板底/粉笔白，先只改“内容语法”，不同时换风格。
- 字幕：单行 12–16 字；静态；不逐词高亮；不把定义放屏上。
- 旁白：Qwen TTS 同一音色，语速降到约 3 字/秒；无 BGM；关键处留 2s。
- 版式：全屏一条线；顶部最多一行小标题；底部字幕；没有左右卡片。

## 7. 验收门槛

- 5 个真实观众（初一或同等）：
  - 4/5 能用自己的话解释 -3 < -1；
  - 4/5 能做对 -5 与 -2；
  - 4/5 更愿意看完新版，而不是旧版；
  - 至少 3/5 能指出“看位置”这个关键。
- 结构：
  - 单 Scene ≤33s；
  - 每 4–8s 有一次有意义变化；
  - 一个视觉锚点贯穿 S1–S4；
  - 没有“纯卡片念定义”超过 10s。

## 8. 失败时怎么改

- 如果观众仍觉得闷：先改**视觉事件密度/变化幅度**，不是加 MG；
- 如果听不懂：改**模型**（温度计→数轴的变形是否清楚），不是加字幕；
- 如果只记住规则不理解：加一个“先猜/反例”镜头，不是多讲一遍；
- 如果 5 人仍无感：考虑手写/实拍/Manim，而不是继续堆 Remotion 卡片。
