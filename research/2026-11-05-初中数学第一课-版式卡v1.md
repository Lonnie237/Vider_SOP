# 初中数学第一课 · 版式卡 v1

- 日期：2026-11-05
- 方法：[分镜版式卡](../knowledge/方法论/storyboard-layout-cards.md)
- 对应分镜：[分镜 v1](2026-11-05-初中数学第一课-分镜v1.md)
- 结论：**每个分镜都要做版式设计，但不是每个都重新发明一套版式。** 8 个 Scene 用 4 个母版 + 1 个封面，逐镜填「版式卡」。

## 1. 为什么要逐镜设计

- 内容不同：问题、对照、三例、数轴、清单、收尾，焦点和空间关系不同；
- 不逐镜设计 → 每镜像 PPT 模板，观众不知道看哪；
- 每镜都原创 → 视觉语言碎，制作成本高，观众要重新学构图。

正确做法：**全局设计系统（一次）+ 4 个母版（一次）+ 每镜一张版式卡（8 次微调）**。

## 2. 母版与 Scene 映射

| 母版 | 用途 | Scene |
|---|---|---|
| A 全屏问题/主物 | 一个问题 + 一个主视觉 | S0 封面、S1 开场、S7 回收 |
| B 左右对照 | 两种规定/两个状态 | S2 规定 |
| C 三格/清单 | 三个例子/三个检查 | S3 0、S6 三个坑 |
| D 全宽数轴 | 位置、比较、距离 | S4 数轴、S5 比较 |

> 8 个 Scene 不是 8 套版式，而是 4 套母版 + 逐镜变化。这样既统一，又不模板化。

## 3. 全局网格

| 项 | 值 |
|---|---|
| 画布 | 1920×1080 |
| 内容安全边距 | 左右 96；上 48；下 154 |
| 网格 | 12 列，列宽约 124，gutter 24 |
| 标题 | 72–96px，1–2 行 |
| 正文 | 32–40px |
| 标签 | 22–26px |
| 字幕 | 单行 12–16 字，底部 50px |
| 主焦点 | 每镜 1 个 |
| 最大文字块 | 3 行以内；超了拆镜 |

## 4. 逐镜版式卡

### S0 封面（母版 A）

- 结论：0℃ 以下，也是温度。
- 构图：标题居中偏上；右侧温度计竖放；底部副标题。
- 焦点：标题；温度计只做氛围。
- 层：黑板底 → 粉笔网格 → 温度计 → 标题 → 副标题。
- 揭示：标题粉笔写入 0.3s；温度计静止。
- 转场：硬切 S1。
- 风险：标题过长；最多 2 行。

### S1 开场（母版 A + 左主物）

- 结论：-3℃ 不是“零下三”的口语问题，是数学写法；0℃ 不是没有温度。
- 构图：左 5 列温度计（3℃→-3℃）；右 7 列问题卡；底部字幕。
- 焦点：-3℃ 与 0℃ 两个数字；温度计只做因果。
- 揭示：水银下降先于旁白「-3」；问题卡在「0℃」处出现。
- 动效：水银 2s 下降；-3 出现时红/蓝分界；不逐词高亮。
- 屏显：-3℃ / 读作：零下三摄氏度 / 0℃ 是？
- 风险：温度计刻度太小；数字至少 40px。

### S2 规定（母版 B）

- 结论：同一组量，规定不同，符号相反；符号是规定，不是好坏。
- 构图：左右两栏等宽（各 5.5 列），中间 1 列留白；两卡同高。
- 焦点：当前规定的一栏；另一栏压暗 20%。
- 揭示：两卡先在场；旁白说「规定收入为正」时左卡亮；说「规定支出为正」时右卡亮。
- 动效：数字翻牌 0.3s；正负号单独放大 0.2s。
- 屏显：规定收入为正：+200 / -150；规定支出为正：-200 / +150。
- 风险：两栏同时亮会没有焦点；只亮当前栏。

### S3 0（母版 C）

- 结论：0 个=没有；0℃/0 米=确定点；0 是分界。
- 构图：三格横排（各 4 列），中间大 0 叠在第三格上方？不，0 放在三格中线上方。
- 焦点：0 的分界含义；三格是证据。
- 揭示：三格按旁白顺序出现；0 最后放大。
- 动效：0 从 0.8→1.2 再回落 1.0；粉笔圈「分界」。
- 屏显：0 个苹果 / 0℃ / 0 米海拔 / 0 是分界。
- 风险：三格 + 大 0 可能拥挤；0 放上方不占格。

### S4 数轴（母版 D）

- 结论：数轴三要素；右 > 左；-3 < -1。
- 构图：全宽数轴（x 120–1800，y 560）；上方标题；下方字幕。
- 焦点：-3 与 -1 的位置关系。
- 揭示：先画直线 → 原点 → 正方向箭头 → 单位长度 → +3/-3 → -1 → 预测卡。
- 动效：粉笔画线 0.6s；刻度逐个出现；预测停 2s；答案时 -3/-1 高亮。
- 屏显：原点 / 正方向 → / 单位长度（每格等长）；不写「-3<-1」答案。
- 风险：单位长度没标清；箭头必须画；点数不要挤。

### S5 比较（母版 D 变体：局部放大）

- 结论：-100 < -1；负号后的数越大，位置越靠左，值越小。
- 构图：数轴只保留 -100 到 0 的局部；两点在画面左右；不等号最后落位。
- 焦点：-100 与 -1 的相对位置。
- 揭示：先只出两点 → 预测 1.5s → 画连线 → 不等号。
- 动效：线从 -100 拉到 -1；不等号弹入。
- 屏显：-100 vs -1 / 先猜。
- 风险：与 S4 太像；用局部放大 + 预测区分。

### S6 三个坑（母版 C 变体：三拍）

- 结论：0 个 vs 0℃；负号 vs 减号；-5 < -2。
- 构图：三拍硬切，每拍一个 16:9 小舞台；每拍只留一个对照。
- 焦点：每拍一个冲突点。
- 揭示：先问 → 停 1s → 答。
- 动效：每拍只做一次高亮（圈/线/变色）。
- 屏显：0 个 vs 0℃ / 负号 vs 减号 / -5 vs -2。
- 风险：三拍挤在 35s；每拍≤10s。

### S7 回收（母版 A + 三卡）

- 结论：三个工具；下一站有理数分类；挑战 -2→3。
- 构图：三卡横排 + 下方问题卡；温度计收起。
- 焦点：三个工具关键词；问题卡第二焦点。
- 揭示：三卡依次出现；问题卡 HOLD 2s；答案最后 1s。
- 动效：卡片落位；问题卡轻微呼吸。
- 屏显：规定 / 0 的分界 / 数轴看位置 / -2 → 3 = ? 格。
- 风险：问题卡与三卡抢焦点；问题卡放底部，弱化。

## 5. 每镜必须填的 8 个字段

1. 一句话结论；
2. 母版；
3. 网格/构图（左右/中心/全宽）；
4. 唯一焦点；
5. 元素层级（z-order）；
6. 揭示顺序（先结构还是按锚点）；
7. 动效（≤1 个主要动作）；
8. 字幕/屏显/转场/风险。

## 6. 验收

- 每镜都有且只有一个焦点；
- 同一母版的 Scene 结构一致，但焦点不同；
- 没有「每镜一张新海报」；
- 字幕单行、屏显不复述；
- 9:16 版本需重排，不缩放。
