# 初一学生评审（第二轮 · 看 v3）

> 评审人：同一个初一新生（12 岁，数学中等，注意力容易跑），六下人教版「负数」学过但只记得个大概。
> 只看了脚本，没看视频。前面 §1–§6 的表我扫了一眼就跳到 §7。不懂就写不懂。

## 第一反应

1. 标题换了：「0℃ 以下，也是温度」。**这个我一看就懂，比上一版「负数不是“负”」好太多**——上一版我以为是讲错别字。现在我会想知道“那零下到底算不算温度”，有好奇心。
2. 但标题只在讲 0℃，我翻到后面发现还有数轴、还有“规定”。**标题和内容对不上**，我会以为这课主要是讲温度。
3. 3:55。上版 5:35，我嫌长。现在短了，这是好事。
4. 看到 Brief 里写「先备知识：六下第一单元「负数」已学」，我的第一反应是：**“那这课不就是复习吗？”** 这个念头一冒出来，我从 S1 就想快进。后来发现不是，但一开始的松懈已经发生了。
5. 我第一件事是回头找上一轮我卡的那 5 个点。找到 4 个改了，1 个（负号/减号）我把 S1–S7 翻了三遍没找到。心里“哦，这个忘了”。

### 按时间线

**S0 封面 0:00–0:04**
「0℃ 以下，也是温度」——懂。但“初中数学第一课”和温度摆在一起，我会以为这 4 分钟都在讲温度。

**S1 开场 0:04–0:32**
- 语序和读法都好了，这是 v3 最直接的进步。✓
- 新冒出一个小岔子：「也可以读「负三摄氏度」」——**那我上课到底读哪个？** 我要是读“零下三”，老师会不会说错？这个问题没人管，它会跟着我到 S2。不用讲很深，补半句“课本上一般读负三”我就踏实了。
- 「0℃ 又是不是「没有温度」？」——好问题，我会跟着想，不困。
- 但 28 秒里讲的“零下写成 -3”我六下学过。**松懈点 1**：我会觉得“这个我知道”，然后注意力先掉一半。

**S2 规定 0:32–1:20（48 秒，全场最长的段）**
- 「小学六年级你学过负数：温度、存折」——这句一出，我就确认“哦，复习时间”，往椅背上一靠。**这是我这次最可能跑神的位置**，因为开头 1 分 16 秒里有一半是我学过的。
- 「不是记住「零下写负号」，而是理解——同一组相反意义的量，怎么用一套符号统一表示」——这句在讲道理，没例子。**「统一表示」我还是 get 不到**：是“都用符号记”，还是“能互相换算”？我没听懂，但这次我懒得问自己，就当听过了。
- 存折那段（规定收入为正 / 规定支出为正，左右两栏）**是全场最有用的一段**。同一组数换一栏，我一下就懂“规定”是什么了。这是 v3 比 v2 强最多的地方。
- 但「两种规定都行」让我**不安，不是不懂**：我印象里数学题只有一个正确答案。你说两个都行，我会怀疑自己听错，接下来 30 秒都在想“那考试我写哪个”。补一句“题目会告诉规定哪个”就解决了。
- 还有一个显眼的东西没人管：屏幕上出现了 **+200、+150**。我不认识这里那个「+」，视频从头到尾没解释。上一版没这个符号，这一版有了，反而更扎眼。

**S3 0（0 个 / 0℃ / 0 米）1:20–2:00**
- 三格对照很好，**我一遍就懂**，这是我唯一能确定“我学会了”的一段。✓
- 「所以 0 有两种用法：记数时表示「没有」；作刻度或基准时，是一个确定的点。」——**这句我会记成“0 有时候是没有，有时候不是”**，但“哪个是哪个”得在脑子里分两栏存，一紧张就会串（后测 Q6 有写反的风险）。
- 「0 既不是正数，也不是负数，它是正负数的分界」——说了，可“分界”这个词我不熟。如果说成“0 站在中间，正数负数它都不算”，我一遍就记住。现在我得背。

**S4 数轴 2:00–2:50**
- 单位长度解决了 ✓。
- 「先别急着信：-3 和 -1，谁大？停两秒」——**这是 v3 最好的设计。** 我第一次在视频里被叫醒，真的会去看。上轮我说“你让我别想，不是让我懂”，这轮至少让我自己验了。
- 但 2 秒太紧：我还在想 -3 和 -1，画面已经往下走了。3 秒刚好。
- **有个东西全片没出现：「箭头」。** 我知道“正方向”这三个字，但不知道画数轴时正方向是用箭头画的。后测 Q11 的判分要求“原点/正方向/单位长度等距/四点位置/箭头”五项全对才给 1 分——我漏箭头，直接 0 分。**这不怪我，是没人教。**
- 「数轴上，右边的数总比左边大」还是规则，但“先别急着信 + 停两秒”让它不像灌输，我能接受。不过**“为什么右边大”我依然说不出来**，只能说“看数轴就是这样”。

**S5 比较 2:50–3:25（35 秒）**
- **这是全场我觉得最“空”的地方。** S4 刚刚用“先猜后验”做完了 -3 和 -1；S5 又用同一个模子做 -5 和 -2，而且旁白还是“我讲给你听”，不是我猜。
- 35 秒我只会想：“这不刚讲过吗？”——**这一段可以删，或者换个讲法。**
- 唯一有用的是口诀「负号后面的数越大，位置越靠左，值反而越小」。**但这句应该放在 S4**，放 S5 等于让我在重复里捡到一颗有用的糖。

**S6 回收 3:25–3:40**
- 三个工具：先规定正方向 / 0 是分界 / 数轴看位置。快，跟得上。
- 但我发现：**三个工具里没有“负号≠减号”，也没有“0 个 vs 0℃”**，而后测 Q4 考 +号、Q6 考 0 个/0℃。**回收的和考的不是同一套东西。**
- 「接下来学有理数的分类，再用数轴看相反数和绝对值」——又一口气三个新词。这次只 15 秒且马上结束，我没上版那么慌，但我还是不知道它们是什么。

**S7 挑战 3:40–3:55**
- 「从 -2 到 3，要走几个单位长度？先数格子」——**比上一版清楚多了。** 上版“电梯经过几层”我不知道数楼层还是数间隔；这版 S4 讲了单位长度，我知道要数格。我在心里数：-2→-1（1）→0（2）→1（3）→2（4）→3（5），5 格。✓ 这个改得好。
- 但 **HOLD 1.5 秒不够**：我数到第 2 格，画面就没了。而且**不给答案**，我数错也不知道。上一版“留个问题不答”的毛病，换了个说法，还在。

## 会记错 / 混淆

1. **「0 有两种用法」我会把两栏串起来。** 记数=“没有”、刻度=“确定点”，但哪个是哪个，我考场上要靠例子反推，容易写反（Q6）。
2. **「0 是分界」我仍然可能记成「0 是正数」。** 视频说了“既不是正数也不是负数”，但“分界”这个词本身不提示“它两边都不属于”。我上一轮就写会记错成“0 是正数”，这轮风险还在，只是低了一点。
3. **「+200 / +3 里的 +」我会当成加法符号。** 全片没讲“+ 是正号”，后测 Q4 偏偏直接考这个。我上一轮提过“正号没讲”，这轮补进了误区表 M2 的行（说的是负号），**正号还是没人讲**。
4. **「负号 vs 减号」我依然会翻车。** 上一轮说我“遇到 -3-5 这种两个负号连在一起就懵”，这轮脚本没碰这个点。-3 是负数、3-5 是减法我懂，**-3-5 我依然不敢下手**。
5. **「正方向」我会记成“往右”，但不会记成“要画箭头”。** 因为视频只说“向右为正”，没说画法。Q11 会漏这项，整题 0 分。
6. **「单位长度」这次记对了**（一格代表多少、每格一样长）✓，但“一格可以自己规定代表几”我**还是不确定**——旁白像在说“有一格代表几”这个既成事实，不像在说“你可以选”。所以真让我画，我可能不敢标“1”。
7. **「两种规定都行」我可能记成“随便写都对”。** 脚本说了“同一道题只能选一种”，但没告诉我“题目会指定”，所以我概念上会把“两种都行”扩大成“没有唯一答案”。

## 一句话复述

能说，但新东西说不全：

> 「同一件相反的事，用正负号来记，怎么记是人为规定的；0 不只是“没有”，它还是个刻度，站在中间；数轴上右边的数比左边大。」

- “人为规定”我能说，“规定可以换、两种都行”我会漏。
- “0 既是刻度又是没有”我能说——**这是 v3 教得最好的一点**，我确定我学会了。
- **但如果有人问我“这课和六下学的有什么不一样”，我答不上来。** 我会说“就是又学了一遍负数，多讲了数轴”。这可能才是 v3 真正的问题：它把“规定”这个唯一的新东西，埋在了“你学过负数”的复习里，我没觉得它是新的。
- 让我回答 S1 自己提的“为什么数学要写成 -3”——**我还是答不上来。** 我知道符号是规定的，但说不出“为什么必须有一套统一符号”。这课问了这个问题，没收走它。

## 最该改的 3 处

1. **把「负号不是减号」和「+ 是正号」真正放进视频里；不放进就别考。**
   现在 §4 第 49 行写着「-3-5 里两个「-」各司其职」，但 S1–S7 旁白一个字没讲；后测 Q4 却考「+3 的 + 只表示加法」。这是全片最硬的错配：**我看了视频，Q4 还是要猜。** 最小改法：S2 存折屏显里有 +200，旁白顺手加一句“这个 + 是正号，不是加法”；S6 三卡里加一张“负号≠减号”；S3 的“0 个 vs 0℃”也塞进 S6 回收。要么就把 Q4 删掉，别考没教的东西。这也是上一轮 5 个卡点里唯一没解决的。

2. **S5（2:50–3:25）别再拿同一个模子讲第二遍，把“讲”换成“你猜”。**
   S4 已经完整做过 -3 和 -1 的“先猜后验”，S5 又是 -5 和 -2，还是你讲完，我只会想“刚讲过”。两个改法任选一个：**(a)** 换成让我“啊？”的一对，比如 -100 和 -1——我本能觉得 100 大得多，结果 -100 更小，这个冲击能记住；**(b)** 保留 -5/-2，但把旁白删掉，改成“停三秒，你猜”，让我自己踩坑。另外把「负号后面的数越大，位置越靠左，值越小」这句口诀**提前到 S4**，S5 才有新内容可讲，不然它就是在重复里捡糖。

3. **S4 补一句“正方向画成箭头”，S7 的停顿加长并给答案。**
   Q11 是五项全对才给 1 分，但 S4 只说了“规定原点、正方向、单位长度”，“正方向用箭头表示”全片没出现（我 grep 过，只有 Q11 那一行有“箭头”）。**教了但没教全考核项，等于白丢一题。** 同时 S7 只 HOLD 1.5 秒，我数 5 个格跟不上，而且不给答案——上一轮“留个问题不答”的毛病换了个壳还在。画完数轴补一张“5 个单位长度”的答案卡，多给 2 秒，我才知道自己数对没。
