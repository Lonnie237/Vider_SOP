# 初一学生评审

> 评审人：初一新生（12 岁，数学中等，注意力容易跑）。只看了这份脚本，没看视频。
> 读法：前面 §1–§7 的表格我扫了一眼就跳过了，主要看 §8 的脚本表。下面是老实说的。

## 第一反应

1. 标题「负数不是“负”」我第一眼看不懂。负数不就是负的吗？我以为是在纠正一个错别字，或者要讲「负」这个词本身。看了 30 秒才知道不是这意思。这个标题会让我一开始就有点防御（“是不是我又理解错了”）。
2. 打开文件，前面是一堆 Brief、ABCD 目标、概念图、误区表、门禁表。**我直接划到 §8 了**，那些表格我一个字都不想看。如果这是给老师看的没问题，但如果先给我看，我会觉得“这课好长好正式”。
3. 看到「约 5 分 30 秒」，还行，比一节课短，这个我能接受。
4. 但整份脚本 5:30 里全是旁白在讲，**没有一处让我自己算、自己答、自己动手**。我心里先记了个“可能会困”。

## 按时间线的卡点

**0:00–0:05 封面**
「负数不是“负”」——不懂。我会猜：是不是说负数不是“减去”的意思？还是说负数不该读成“负”？猜不出来。

**0:05–0:35 开场**
- 这句我要倒回去：「为什么不写“零下 3℃”就行？」——这句话我读了三遍。到底是“不写零下3℃能行吗”，还是“不写零下3℃就行了”？语序绕，我第一遍理解成“为什么可以不写零下3℃”。**这一句是全场第一个卡点。**
- 屏幕上是写着「-3℃ 怎么读？」，但是接下来的旁白**一直没告诉我怎么读**。我等了半天，没人说“零下三摄氏度”或者“负三摄氏度”。这个问号挂在那儿，我心里就一直有个没关掉的问题，后面听别的内容会分心。
- 「0℃ 是没有温度吗？」这个我能跟着想，因为冬天我摸过冰，这个我有感觉，OK。

**0:35–1:35 为什么（S2）**
- 「生活里有很多相反意义的量：零上/零下，收入/支出，海平面以上/以下」——**这不就是废话吗？** 零下、支出、海拔这些词我小学就听过，不用你告诉我它们相反。这一分钟我在心里说“然后呢”。
- 真正的问题是「如果只用正数，数学就没法统一计算」——「统一计算」这四个字我 get 不到。什么叫没法统一计算？没算给我看啊。我脑子里没有“不统一”的样子，所以这句等于没听懂。
- 这一分钟全是话，屏幕上就三张对比卡，画面基本不动。**这是我第一个会跑神的地方**（后面 S3 还有一分钟，加起来连着两分钟讲解，我大概会在 1:10 左右开始想别的）。
- 「先定一个基准」——基准是什么？是 0 吗？如果不是 0，那“基准以上记正”还成立吗？我拿不准。脚本没说清，我就自己猜了一个，猜错了后面全歪。

**1:35–2:35 定义（S3）**
- 「大于 0 的数叫正数；在正数前面加“-”的数叫负数。0 既不是正数，也不是负数」——这三句我要倒回去一遍。不是因为难，是因为**一下子来了三个定义，没有停顿**。我记住了第一句，第三句就飘了。
- 「在标准大气压下，它是水的冰点」——这里我彻底卡了。**冰点是什么？标准大气压是什么？** 这是物理不是数学吧？我上一节物理还没上呢。我就记住“0℃ 是冰点”这四个字，但“冰点”我不懂，等于没记住。
- 屏幕上「正数 > 0 / 负数 < 0 / 0 是分界」——这个我看懂了，比旁白清楚。**建议旁白少讲点，屏显已经讲明白了。**

**2:35–3:50 数轴（S4）**
- 「规定原点、正方向、单位长度」——听得懂名字，但我不知道**为什么是这三个**，也不知道**单位长度是什么意思**。是“一格 1 厘米”还是“一格代表 1”？还是“每格必须一样长”？脚本没说。我猜成“一格代表 1”，但我不确定。
- 「+3 在原点右边 3 格」——这个“3 格”是哪来的？如果单位长度不是 1 呢？这句我跟着点头，但其实没真懂。
- 「数轴上右边的数总比左边大」——这句话我记住了。**记是记住了，但我不信。** 因为 -3 的“数字”是 3，-1 的“数字”是 1，3 比 1 大，你让我怎么相信 -3 更小？这一段的“不信”我一直带到 S5。

**3:50–4:40 比较（S5）**
- 「所以 -3 在 -1 左边，-3 < -1」——**这个“所以”跳步了。** 为什么 -3 就在 -1 左边？我画的时候会想“-3 离 0 更远啊，更远不是更大吗”。这个疑问视频里没有回答，只说“不要看数字大小，要看位置”。**“不要看”是让我别想，不是让我懂。** 不解释原因，我考试会靠背，背错了就完。
- 「不要看“数字大小”，要看它在数轴上的位置」——这句话我 get 到了字面，但心里不服气。如果换一道没画数轴的题（比如问 -7 和 -2 谁大），我可能又回到“7 比 2 大”。

**4:40–5:20 误区（S6）**
- 「负号不是减号」——**这个我 get 不到。** 3-5 里的“-”是减号，-3 里的“-”是负号，可它们长得一模一样啊，我怎么一眼分出来？脚本说“写在数前是负号，写在两数之间是减号”，那 -3-5 呢？前面那个是负号、后面那个是减号？这一瞬间我就乱了。这一条我觉得视频讲得太快，而且**举的例子 -3 和 3-5 都不够难**，一难我就不会了。
- 三个坑 40 秒扫三句，前两个我懂一点，第三个跟 S5 说的一模一样，**这是在重复，不是在教我**。40 秒里塞三条，我一条都没记住。
- 这里也是我会跑神的地方，因为快结束了，我脑子已经准备下课了。

**5:20–5:35 收尾（S7）**
- 「下一课我们再学相反数、绝对值和有理数运算」——**这三个词我一个都不认识。** 一口气报三个新词，还是我不懂的，我会有点慌：“完了，下节课会不会更难”。
- 「留个问题：电梯从 -2 层到 3 层，要经过几层？」——**这是个坑。** 我会答 6（-2、-1、0、1、2、3 六个楼层），或者答 4。但答案说是 5 个间隔。**“经过几层”到底是数楼层还是数间隔？** 我自己想不出来，而且视频到这儿就结束了，也没给我答案，我猜完也确认不了。
- 还有一个细节：题目里“电梯”和“间隔”其实不是一回事，但脚本里没区分，我会混。

## 会记错/混淆的点

1. **「0 是正负数的分界」我会记成「0 是正数」**。因为“分界”这个词我平时不用，但“0 是正数”我小学说过。这两个最容易在我脑子里掉包。
2. **「单位长度」我会记成「一格 1 厘米」，或者干脆记漏**。三要素我背得出“原点、正方向、单位长度”，但“单位长度要每格一样长、每格代表多少要定死”，视频没说，我考试画数轴很可能会一格大、一格小。
3. **「负数的定义」我会记成「前面带“-”的数」**，忘了“在正数前面加”。这样 0 前面加“-”写成 -0 我也以为是负数。而且**“+3”里的“+”号脚本从头到尾没讲**，我可能以为 +3 是“加号 3”，或者以为是 3。
4. **「右边的数比左边大」我会记反成「负号越多越大」**。因为 -3 看着“数字 3 更大”，我凭直觉会选 -3 > -1。视频说“不要看数字大小”，但没告诉我为什么不看，我信不了，一紧张就回到直觉。
5. **「负号 vs 减号」我会在 -3-5 这种式子上翻车**。视频只给了 -3 和 3-5 两个“干净”例子，没给混合的，我一遇到两个负号连在一起就懵。
6. **「0℃ 是冰点」我会记成「0℃ 的水就是冰」**。这不怪视频，但“冰点”这个词没解释，我可能推成“0℃ 一定是冰”，以后遇到 0℃ 的水就错。

## 后测题体感

1. **判断题（-5、0、+3、-0.5）**：能做，但**会犹豫两个地方**。第一是“+3”，那个“+”号视频里压根没出现过，我要猜它是“正号”还是“加号”。第二是“-0.5”，小学没学过带小数的负数，我会先想“-0.5 是负数吗”，然后靠“前面加负号”推出来。**这题我大概 60% 有把握，会猜一下 +3。**
2. **用正负数表示（温度/收支/海拔）**：温度、海拔我有把握。**收支这一组我会卡**——题目说“先定基准”，但基准是谁？我心里得自己找“收支平衡”，视频里没教过怎么把“平衡”当成基准。而且“收入 200 是 +200”这个，我可能是背下来的，不是推出来的。**这题我会做一半猜一半。**
3. **解释“0℃ 不是没有温度”、0 是什么角色**：**这题我基本靠背视频里的原句，不会用自己的话。** “冰点”我本来就不懂，写出来也是抄的。**会猜。**
4. **数轴画 -3、-1、0、2 并比较**：画位置我能画对（记住“0 居中，左右各数格子”）。**但“单位长度”我会写错或写漏**，一格画多长我自己定。比较那两问，“-3 < -1”我是背下来的，**手会抖，可能会写成 -3 > -1**。
5. **电梯从 -2 到 3 几层**：**这题我不会，纯猜。** 5 还是 6 拿不准，而且我得先想明白“经过几层”是数楼层还是数间隔。视频最后就提了这个问题没答案，我猜完也不知道对不对。

**总体**：5 题里 2 题有把握（2 的温度/海拔部分、4 的画图部分），2 题要靠猜（1、5），1 题纯背（3）。达不到“5 题对 4 题”。

## 一句话复述

能说，但说得不完整：

> 「生活里有相反的两边，所以要用正数和负数来记，0 是中间那条线，数轴上越往右数越大。」

**但我说的时候会漏掉“0 既不是正数也不是负数”**，也说不清数轴为什么有用——我会说“数轴就是把数排一排”。而且**看完我最记得的一句话其实是“0 不是没有”**，因为 S6 又说了一遍，重复让人记得，但它不一定是最重要的东西。

## 最该改的 3 处

1. **0:05–0:35 开场那句话改直白，并且把“-3℃ 怎么读”当场回答掉。**
   「为什么不写“零下 3℃”就行？」语序太绕，我读三遍都不确定意思。改成一句能一遍听懂的话，比如“零下 3℃，数学上为什么写成 -3℃？”。而且屏显上挂着「-3℃ 怎么读？」这个问号，旁白必须**立刻给答案**（“读作零下三摄氏度，也叫负三摄氏度”），不能让问号一直亮着。现在我全程在等这个答案，注意力被它拽走了。

2. **0:35–1:35（S2）这两分钟别再纯讲，得让我看见“相反”。**
   “零上/零下、收入/支出、海拔”我小学就知道相反，这不叫教，这叫重复。真正要给我的是**一个具体数字在动**：温度计从 3℃ 一格一格降到 -3℃，每降一格屏幕上的数变一次，我能看见“这边是正的、过了 0 就到负的”。顺便在这段把“基准就是那个 0 点”说死，别让我自己猜基准。现在 S2 加 S3 连着两分钟纯旁白，我肯定在 1:10 左右跑神。

3. **2:35–4:40（S4+S5）把“单位长度”和“为什么左边小”讲透，别只给规则。**
   三要素现在只报了三个名字，“单位长度”我根本不知道是什么（一格 1 厘米？一格代表 1？每格必须一样长？），这会直接毁掉后测第 4 题。比较那段“不要看数字大小，要看位置”是**让我别想，不是让我懂**——得解释一句“越往左，离 0 越远，负得越多，所以更小”，不然我考试只能背，背反了就全错。这两处正好是 O3 的两个卡点，比再讲一遍“0 不是没有”有用。

**补充（不改脚本，只是说一句）**：4:40–5:20 那三个坑里，第三个跟 S5 重复了，我听完没多学到东西。如果非要腾时间，我宁愿它多给我 5 秒讲清“-3-5 里两个‘-’分别是什么”，因为那个我是真会错。
