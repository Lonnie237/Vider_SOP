## P0（时间码 → 问题 → 改法）

**P0-1 · 0:05.7–0:10.5 / 0:12.8–0:14.6 / 0:33.7–0:39.3 —— 字幕与旁白系统性错位：提前 2.27s、≈4.9s 有声无字幕、2 处字幕不是旁白说的话**

- 0:05.7：字幕已跳到「0℃ 是没有温度吗？」，旁白此刻还在「…也可以读负三摄氏度」（该句真实 7.98–10.51s）→ 提前 2.27s。
- 0:07.7–0:10.5：旁白念最后一句，字幕空白 2.78s（b01 字幕覆盖率 60%，尾缺 2.82s）。
- 0:12.8–0:14.6：字幕写「同一组相反意义的量」，旁白说的是「初中要理解：同一组量」——「相反意义的」是字幕自己加的。
- 0:33.7：字幕「0 米海拔是海平面」早于旁白 0.76s（该句 34.47s 才起）。
- 0:35.3–0:37.1：字幕「0 是正负数的分界」，旁白实际在念「0 **既不是正数，也不是负数**，是分界」；0:37.1–0:39.3 旁白未停，字幕空白 2.13s（b03 覆盖率 72%）。
- 根因：[make_audio.py L17–L18](../../pipeline/remotion/junior-math-first-lesson/tools/make_audio.py#L17-L18) 的 cue 表与 TTS 文本不是同一份字符串（漏「也可以读负三摄氏度」、改词「相反意义的」、符号写法不同），cue_times 找不到就在字符游标上硬推 → 级联错位。QC 只查「长度/重叠」就写「通过」，这层门禁等于没有。
- 改法：TTS 前把数字/符号写死中文读法（-3℃→负三摄氏度、0℃→零摄氏度、+200→正二百），**用这份转写后的文本切 cue**；生成后加断言：每个 cue 必须能在 words 序列命中，否则直接 fail；QC 增加「字幕-旁白起止偏差 ≤±0.2s、有声段覆盖率 ≥98%」两项。

**P0-2 · 0:00.0–0:04.0 / 0:53.8–0:57.3 —— 配音文本缺陷把「预测 2 秒」做成了「念出停两秒」，开头还重复一遍「零下三摄氏度」**

- 开头：旁白是「天气预报最低**零下三摄氏度**；读作**零下三摄氏度**，也可以读负三摄氏度」——TTS 把「-3℃」直接读成「零下三摄氏度」，与下一句「读作零下三摄氏度」撞车，v4 想立的「写法 vs 读法」对比被吃掉，听感是重复。根因是 [make_audio.py L17](../../pipeline/remotion/junior-math-first-lesson/tools/make_audio.py#L17) 把「-3℃」原样交给 TTS。
- 0:53.8–0:57.3：旁白念出「停两秒，看：」——这是舞台指示，不是台词；屏显同时写「停两秒，再看数轴」。
- 预测窗口实测：问题音频结束 55.56s → 答案音频 57.31s，共 1.75s；其中 0.61s 在念「停两秒」、0.31s 在念「看：」，真正静默合计 **0.83s**（0.15+0.23+0.45）。版式卡/分镜要求 2s 思考窗。
- 改法：口播稿删掉「停两秒/看：」，答案前插真实 2.0s 静默（TTS 后 splice silence，最稳）；-3℃ 等符号在 TTS 文本层写死中文读法，并加「TTS 文本禁止字符」断言（数字、℃、+、-、< 出现即报错）。

**P0-3 · 0:39.8–0:41.2 / 0:39.8–0:57.1 / 0:39.8–0:51.75 —— S4 揭示逆序：点与预测卡先于轴线，标题提前 11.9s 给出结论**

- 0:39.8–0:41.2（≈1.4s）：四个点（-3/-1/0/+3）与「原点 / 正方向 / 单位长度」标签已在场上，轴线只有最左边 3% 的一小段（[MathSample.tsx L195–L199](../../pipeline/remotion/junior-math-first-lesson/src/MathSample.tsx#L195-L199)）——观众看到「悬浮的点 + 没有轴的标签」，分镜的「先画结构再放点」正好演反。
- 0:39.8–0:57.1（17.3s）：预测卡「先猜 / -3 和 -1，谁大？/ 停两秒，再看数轴」从 S4 第一帧就挂着（answer 为 false 时无条件渲染），而旁白 0:53.85 才发问；这 17.3s 里它一直和数轴抢焦点。
- 0:39.8 起：标题「原点、正方向、单位长度；**右边总比左边大**」——本轮要教的规则提前 11.9s 上屏（旁白 0:51.75 才说），版式卡 S4 明令屏显不写答案，换成「规则句」照样是提前给。
- 0:41.2–0:57.1（16s）：画线完成后主体完全静止，唯一动的是背景网格 ±4px 漂移——实际观感就是「先演完，再空转」。
- 另：答案出现时没有「-3/-1 高亮」，只有琥珀文字叠层；「-3 < -1」与字幕「所以 -3 < -1」同屏重复（三轨）。
- 改法：把每个元素绑 anchors——+3 点 0:47.7、-3 点 0:49.8、-1 点 0:53.7（问句出现时再落下并高亮）、轴线 0:42.7–0:43.7（0.6s，绑「先画原点」）、箭头 0:43.7、单位长度标注 0:45.3、预测卡 0:53.3 出现/0:57.4 撤、答案时把 -3/-1 两点与标签变琥珀；标题只留「数轴」。anchors.json 现在只有 3 条，不够。

**P0-4 · 0:29.8–0:30.4 / 0:29.7 起 —— S3 三格 0.7s 内齐出，结论提前 5.6s 上屏**

- 三张卡在 29.8 / 30.1 / 30.4s 全部出现（[MathSample.tsx L146–L148](../../pipeline/remotion/junior-math-first-lesson/src/MathSample.tsx#L146-L148) 的 frame 4/14/24 + S3 起于 29.63s），旁白 30.97 / 32.57 / 34.47 才逐条讲（提前 1.2 / 2.5 / 4.1s）——观众先看完三格，再听讲解。
- 大「0」+「是分界」从 0:29.7 就在（fade 2 帧），旁白 0:35.31 才到「0 是分界」，提前 ≈5.6s；底部「0 既不是正数，也不是负数」0:30.8 就上（提前 4.5s）。
- 分镜要求「三格按旁白顺序出现；0 最后放大；粉笔圈出分界」——0 是第一个出现的元素，且无放大/圈选（[版式卡 S3 L78–L79](../2026-11-05-初中数学第一课-版式卡v1.md#L78-L79) 全未落地）。
- 改法：三格绑 0:31.0 / 0:32.5 / 0:34.4；大 0 与「是分界」绑 0:35.3，0.3s 内 0.8→1.2→1.0；底部结论绑 0:35.3 之后；补 0.2s 粉笔圈。

## verdict

**revise（P0 不为 0：4 条）。**

- 不 pass：字幕-旁白错位（P0-1）、舞台指示被念出+停顿不足（P0-2）是「字幕/节奏」两个核心验证项的硬失败；S4 揭示逆序（P0-3）与 S3 齐出（P0-4）意味着「按锚点揭示」这套全片都要用的机制还没跑通。带着这 4 条铺 S5–S7，会把错误机制复制到全片。
- 不 reject：底座是对的——母版/构图/配色/安全区落地，时间轴由 TTS 驱动且自洽（没有 v2 的假时间轴），单行静态字幕、无底部线、无逐词高亮、响度/分辨率/帧率/首帧全部达标；三目标都有对应镜头与字幕。问题集中在「锚点绑定」和「字幕生成管线」两处，改机制不改结构。
- 样片阶段必须改：P0-1…P0-4（P0-1 建 cue-对齐断言，P0-2 重录 b01/b04 两段，P0-3/P0-4 把固定帧号换成 anchors）。
- 可到全片再改：P1-1…P1-5；其中 P1-3 的三句教学内容必须在全片补回，否则 O2 的误区纠正和 O1 的 M2 都名存实亡。
