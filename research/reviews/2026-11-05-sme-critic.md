## P0（必须改）

### P0-1 后测第 5 题 + S7 钩子：电梯楼层题答案错，且判分会把正确推理判错

- 引原文：L72–L73「应用：电梯从 -2 层到 3 层，一共经过几层？…答案：5 层（-2 → -1 → 0 → 1 → 2 → 3，共 5 个间隔；不要求列减法算式）」；S7 L103 用同一问收尾。
- 为什么错：
  1. **答案自我矛盾**：自己列出 6 个楼层（-2、-1、0、1、2、3），却写"5 层"，紧接又把 5 解释成"5 个间隔"。数轴模型里"点"≠"距离"，而本课最重要的第一个区分正是这个；题目反过来训练两者混用。
  2. **例子本身不成立**：中国住宅/公建电梯普遍没有 0 层（B2、B1、1F、2F、3F）。按真实楼层，-2 到 3 是 5 层、4 段；按题目假想的"有 0 层"，是 6 层、5 段。数字 5 在两种互不相容的读法下都"对"，此题不可判分。
  3. **"经过几层"至少三种读法**：楼层差（5 或 4）、途中经过的中间层（3 或 4）、含首尾的层数（6）。P0 级歧义。
  4. **后果是反教学**：在数轴上数出 5 个间隔的学生写 5 判对；把"层"理解成含两端的写 6、按真实楼层写 4 的都被判错。一道题同时惩罚两种正确思维。
- 怎么改：把题改成纯数轴量，去掉楼层常识：「在数轴上，从表示 -2 的点到表示 3 的点，一共要走几个单位长度？」答案 5 个单位长度（-2→-1→0→1→2→3），不需减法，仍在边界内。要保留电梯，就问"把 -2 层到 3 层画在数轴上，一共上升多少个单位长度"，并在题面写清"只数数轴上的格数，不区分楼层编号"。S7 钩子必须同步改，否则抛出去的仍是歧义题。

### P0-2 起点判错：O1 及其实例情境是小学第三学段的要求，不是初一新目标

- 引原文：L14「先备知识：小学自然数、分数、小数；会画直线、会比较正数大小」；L36 O1「能在给定基准的情境中，用正负数表示相反意义的量（温度/收支/海拔）」；L98 S2 用 60 秒讲温度/收支/海拔三组。
- 为什么错：
  1. 课标原文（第三学段 5~6 年级·综合与实践·主题活动 1「如何表达具有相反意义的量」学业要求）：「在真实情境中，通过具体事例体会相反意义的量，如温度、海拔等，能表达具体情境中负数的实际意义」；第三学段学段目标也写「在主题活动和项目学习中了解负数」。L36 的 O1 几乎逐字等于小学已达成水平。
  2. 教材层面同向：人教版六年级下册第一单元即「负数」（温度、存折/收支、在直线上表示正负数）。初一 1.1 是螺旋复现与形式化，不是首次接触。
  3. 因此先备知识不是"少写一条"，而是**整个起点定位错**：把学生已会的当新学，用 60 秒（全片 335 秒的 18%）复习；真正属于初中的增量（数轴表示、数轴比较、"符号是人为规定"）被压进 S4–S5。
- 怎么改：
  1. L14 改为：「小学第三学段已在主题活动中了解负数（温度、海拔等具有相反意义的量）；人教版六下已学用正负数表示相反意义的量与在直线上表示正负数；会画直线、会比较正数大小」。
  2. O1 按课标第四学段的动词（"理解负数的意义"，不是"表达"）重写：「能在新情境中自主规定哪个方向为正（例如规定支出为正），并说明正负号是人为规定、不代表好坏或大小，5 题对 4 题以上」。
  3. S2 压到 15–20 秒做"唤起+升级"：一句"小学你用温度认识了负数；初中要问的是为什么一套符号能替代所有'零下/支出/以下'，以及怎么把它画成一条线"，省下的时间给 S4/S5。

### P0-3 "0 不是没有"：用全称否定纠正局部误用，会制造新错误

- 引原文：L37 O2「解释『0 是分界，不是没有』」；L55 M1「错误说法：0 就是"没有" → 正确说法：0 既不是正数也不是负数」；L99 S3 旁白只给了 0℃ 的例子。
- 为什么错：0 在记数语境里确实表示"没有"（0 个苹果就是没有苹果），这是学生**正确**的旧知，不能判错；错的只是把它挪到刻度/基准语境（0℃、0 元、海拔 0 米）。v2 用"0 不是没有"一句全称判断覆盖两种语境，等于告诉学生"0 个苹果"这种说法是错的——恰好制造本课最不该有的新混乱。且 M1"为什么错"与"正确说法"不对应：题目问的是"0 是不是没有"，答案只答了"0 不是正数也不是负数"，没回答"那 0 到底表不表示没有"。
- 怎么改：M1 拆两句并限定语境——「记数时 0 表示'一个也没有'；作为刻度/基准时 0 是一个确定的点（0℃、0 元、海平面），不是'没有温度/没有钱'」。O2 改为「能用 0℃ 说明 0 是正负数的分界，并能区分'0 个'与'0℃'两种用法」。S3 补半句"0 个苹果确实是'没有'，但 0℃ 不是'没有温度'"（约 8 秒，从 P0-2 省下的时间里出）。

### P0-4 测评门禁失效：三条目标都写"5 题对 4 题"，与 5 题总量矛盾

- 引原文：L36–L38 三条目标各写「5 题对 4 题以上」；L19「5 道后测 ≥80%」；L113 G4「通过（3 目标 / 5 题）」。
- 为什么错：
  1. 实际映射是 Q1→O2、Q2→O1、Q3→O2、Q4→O3、Q5→O3。O1 只有 1 题、O2 有 2 题、O3 有 2 题，"5 题对 4 题"写在每条目标下不可能成立，每个目标等于没有度数标准。
  2. 更实质：按"总 5 题 ≥80%（对 4 题）"判，O1 全错（Q2 错）、其余全对，仍 4/5 通过——目标明确未达成而门禁放过。G4 标"通过"是虚的。
  3. 判分标准缺失：Q3 两问（0℃ 为什么不是没有温度 + 0 的角色），答对一半怎么算没写；Q4"位置正确"不是可判分描述（三要素画没画？单位长度等距吗？两个不等号算不算分？）。
- 怎么改：
  1. 每条目标按题计分：O1→Q2（3 子项全对）；O2→Q1 全对 + Q3 两问 2/2；O3→Q4（原点、正方向、单位长度等距、四点位置、两个不等号）+ Q5 迁移题（按 P0-1 改写）。
  2. 门禁改为「每条目标都过 + 总分 ≥80%」双条件，避免单目标失败被总分掩盖。
  3. 给 Q4 写判分清单：原点标 0（1）、正方向箭头（1）、单位长度等距（1）、四点位置各 1（4）、两个不等号各 1（2），共 9 分。

## P1 / P2

- **P1-1 标题「负数不是"负"」（L12、L96）与内容零关系，字面上是错的**：负数就是"负"的数；本片真要说的是"负数不是坏/不是没有/不是减号"。S0–S7 无一镜解释，学生只带走一句错误断言。改：换成"0℃ 以下也是温度：负数是怎么来的"；若坚持否定式，必须有一镜点破是"不是'坏'/'没有'"。
- **P1-2 S5 旁白 L101「比较负数，不要看"数字大小"，要看它在数轴上的位置」数学上不成立**：数的大小就是由数轴位置定义的，不是两套并列规则；照字面执行，离开数轴就不会比较，且与教材 1.2.5「两个负数，绝对值大的反而小」表面冲突（绝对值就是"数字部分"）。改："两个负数比较，不能直接比负号后面的数；在数轴上越靠左越小（-3 在 -1 左边，所以 -3 < -1）"。
- **P1-3 S2 L98「数学就没法统一计算」是绝对化无据断言**：本课边界明确不讲有理数运算（L18），这句话承诺的东西全片不兑现；负数在数学史上的动因包含"减法不够减"与债务/相反量，"写起来麻烦"只是表层。改："同一个式子要分几种情况写，没法用一套规则算"，并降级为动机句。
- **P1-4「基准」是自造术语**（L36、L98、L103 收尾还列为三工具之一）：教材/课标口径是"规定：把具有相反意义的量的一种记为正、另一种记为负"。"基准以上记正"会被读成正负由物理上下/好坏决定，收支没有"上下"，隐喻即断。改：术语换回"规定/记为正、记为负"，补一句"正负是相对的：规定支出为正，收入就记为负"（正好接 P0-2 的 O1 升级）。
- **P1-5 §7 自审表虚标（L83）**：L83 写「历史表述 已修：改『最早』为『早期系统记载』」，但 S1–S7 没有任何历史内容；给不存在的内容打"已修"，G1"通过"因此失去依据。另 L79「课标口径 通过：2022 课标要求理解负数、数轴、比较大小」——课标原文（第四学段·数与式·有理数）是「①理解负数的意义（例64）；理解有理数的意义，能用数轴上的点表示有理数，能比较有理数的大小」，v2 无一处引原文/页码，无法核验。改：删该条"已修"，§8 来源列改成"每条 claim → 课标原文/教材节次"，把原文放进台账。
- **P1-6 G1「事实台账 通过（v1 台账 + §7 自审）」不成立（L110）**：v2 没有事实台账（§8 来源列多为"课标/教材 1.1"，无版本/日期），而 v1 台账一半条目（相反数、绝对值、-a、历史）在 v2 已删或未写；拿旧台账给新版盖章是空转。改：在 v2 内生成本课台账（结论/来源/日期/置信度/对应镜头），只保留本课仍成立的条目。
- **P1-7 概念图与序列**：L42–L47 概念图没有"有理数（分类）"节点，S7 L103 却承诺"下一课学相反数、绝对值和有理数运算"。对照目录（1.2.1 有理数的概念→1.2.2 数轴→1.2.3 相反数→1.2.4 绝对值→1.2.5 大小比较→第二章 有理数运算），"下一课"横跨 1.2.1、1.2.3–1.2.5 与整个第二章，不是"一课"；课标第四学段明写"理解有理数的意义"，本课概念图把这个节点整个抹掉。改：补"有理数"节点；S7 改"接下来：有理数的分类，再用数轴看相反数和绝对值"。
- **P1-8 误区表名不副实（L111 G2"5 个误区"）**：M1（0 不是没有）与 M4（0℃ 不是没有温度）是同一误区的两种说法，纠正例都写冰水混合物/冰点；M5「正数一定比负数"大很多"」不是真实误区，且"大小关系看数轴位置"并不反驳它（正数确实大于负数，错的是"大很多"三字）。改：M1/M4 合并；M5 换成真实高频误区，如"0 是最小的数""-15℃ 比 -5℃ 冷，所以 -15 > -5"（后者可作为 M3 的纠正例）。
- **P1-9 时长与旁白量不匹配（可核查）**：全片 335 秒，S0–S7 旁白逐格统计约 345 字，约 1.0 字/秒；口播正常 4–5 字/秒，等于每镜只有约 1/4 时间有声音（S2 60 秒仅 73 字）。要么表内时间不是真实时长，要么成片大面积静默空转，"精确到秒"的验收是假验收。改：按 4 字/秒重排每镜时长或补旁白，并按 P0-2 把 S2 的时间让给 S4/S5。
- **P2-1** Q2 答案「+200 / -150」（L67）缺单位；教材要求记作"+200 元""-150 元"，是否要求带单位未写，会出现漏单位争议。补 rubric。
- **P2-2** Q1（L63）写"判断"但实为分类题；改为"分类：下列各数中哪些是正数、哪些是负数？0 属于哪一类？"
- **P2-3** S4 旁白用"格"（L100"+3 在原点右边 3 格"），屏显用"单位长度"，同一镜两套词；统一为"单位长度"。
- **P2-4** S5 屏显「-3 < -1 < 0 < 2」（L101）比旁白多出 -1 < 0；按 Mayer 一致性，屏显不应先给旁白未讲的关系，留给旁白或删。
- **P2-5** 术语应为课标/教材原词"具有相反意义的量"（L98/L12 缺"具有"），首次出现给全称。
- **P2-6**「0℃ 是水的冰点」（L55、L69、L99）建议补"纯水/冰水混合物"，否则学生可推出"任何水到 0℃ 都结冰"（海水不结冰）。
- **P2-7** O3 要求在数轴表示 -3、-1、0、2（L38），但 S4 只演示 +3 与 -3，-1 和 2 从未在 S4 出现；补齐演示或把 O3 的四个数改与 S4 一致。
- **P2-8** S3 屏显「数轴雏形」（L99）出现在数轴定义（S4）之前；若画面真画数轴，学生先看到未解释结构。建议只放"0 居中 + 正/负两向"的无刻度示意，数轴留到 S4。

## 最危险 3 个问题

1. **后测第 5 题（电梯楼层）是反教学的**：把"点"和"距离"混成同一个数，还依赖现实中不存在的 0 层；正确推理的学生会被判错。它同时是全片最后一个镜头（S7 钩子）和唯一的迁移题，影响面最大。
2. **起点判错（O1 + S2）**：课标第三学段已完成"在温度/海拔等情境中表达负数"，人教版六下整单元讲过；v2 把它当初一新目标，用 18% 时长复习。学生第一课的真实体验会是"初中数学第一课在复习小学"，初中增量（数轴、比较、符号是规定）被挤压。
3. **"0 不是没有" + 标题"负数不是'负'"这对全称否定**：把学生正确的旧知（0 个＝没有）判成错，并在标题给出一个内容从不解释的错误断言；而学生最容易记住的恰恰是标题和"0 不是没有"这两句。

## 结论：revise

不 reject：正数/负数/0/数轴三要素/右>左/冰点/教材节次这些骨架正确，选题也站得住（课标第四学段确有"理解负数的意义 + 数轴表示 + 比较大小"）。但现版本不能进 TTS/渲染，也不能当作"基本可用"送外部教师：P0-1（后测题答案错）、P0-2（起点判错，O1 须重写）、P0-3（"0 不是没有"）、P0-4（目标度数写错、门禁可放过单目标失败）四项必须改完；P1-5/P1-6 的自审与台账虚标须先撤回，G1/G2/G4 改回"部分通过"。改完这四类再走外部教师审 + 5–10 人试播。
