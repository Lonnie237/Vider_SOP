## 3. 概念图

生活情境（温度/存折/海拔）
→ 具有相反意义的量
→ 规定：一种记正，另一种记负
→ 正数 / 负数 / 0（0 是分界）
→ 数轴（原点、正方向、单位长度）
→ 表示与比较
→ 后续：有理数分类 → 相反数 → 绝对值 → 有理数运算

小学六下的负数经验作为「已有基础」旁挂，不是本课新授。

## 4. 误区表（4 条）

| # | 误区 | 正确说法 | 纠正例 |
|---|---|---|---|
| M1 | 0 就是「没有」 | 记数时 0 表示「一个也没有」；作刻度/基准时 0 是确定点 | 0 个苹果 vs 0℃ / 0 米海拔 |
| M2 | 负号就是减号 | 写在数前是负号（性质/方向）；写在两数之间是减号（运算） | -3 是负数；3-5 是减法；-3-5 里两个「-」各司其职 |
| M3 | 负数比较，数字大的更大 | 负号后的数越大，位置越靠左，值反而越小 | -3 < -1；-5 < -2 |
| M4 | 0 是最小的数 | 0 不是最小；负数比 0 小 | -1 < 0 |

| 目标 | 题 | 题目 | 答案/评分 |

| O1 | Q4 | 判断：「+3 里的 + 只表示加法」 | 错；+3 的 + 是正号，表示数的性质 |
| O1 | Q5 | 解释：为什么同一组量可以有两种记法？符号由什么决定？ | 符号由「规定」决定；规定不同，符号相反；不是好坏/大小 |
| O2 | Q6 | 「0 个苹果」和「0℃」里的 0，意义一样吗？ | 不一样；前者记数「没有」，后者是确定刻度 |

| O2 | Q8 | 0℃ 是「没有温度」吗？为什么？ | 不是；0℃ 是温度计上的确定温度 |
| O2 | Q9 | 0 米海拔表示什么？ | 海平面；是一个基准点，不是「没有高度」 |
| O2 | Q10 | 判断：「0 是最小的数」 | 错；负数比 0 小，如 -1 < 0 |
| O3 | Q11 | 画数轴，标出 -3、-1、0、2 | 原点/正方向/单位长度等距/四点位置/箭头，共 5 项 |
| O3 | Q12 | 比较 -3 与 -1，并说明理由 | -3 < -1；-3 在 -1 左边 |
| O3 | Q13 | 比较 -5 与 -2，并说明理由 | -5 < -2；-5 在 -2 左边 |
| O3 | Q14 | 数轴上 -4 与 -1，谁更靠左？谁更小？ | -4 更靠左；-4 更小 |
| O3 | Q15 | 从 -2 到 3，在数轴上走几个单位长度？ | 5 个单位长度；不要求列减法 |
