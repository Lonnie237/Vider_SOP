# 网站采集工程师 · 推广方案 v1

- 日期：2026-11-11
- 产品页：https://www.workbuddy.cn/share/asset?shareCode=18aKqjixT0zP5tQ6LaFpir&sig=HHGC5AiNRqMgKf2D
- 产品：WorkBuddy「网站采集工程师 · 定制化网站采集专家」
- 当前数据：v1.3.0，使用量 131，开发者 Lonnie
- 目标：增加资产页打开 → WorkBuddy 打开 → 首次任务完成 → 7 日留存

## 1. 产品一句话

**把网址交给它，把数据还给你。**

给网址和想要的字段，它自动定位数据接口、搭好每日定时采集；增量去重、失败通报，大多数站点当天出数；交付前和官网逐条对照，零代码。

## 2. 目标人群

优先级从高到低：

1. **运营/市场**：每日行情、竞品价格、资讯监控、活动页面；
2. **销售/商务**：招标信息、名单、线索、价格表；
3. **电商**：价格、库存、评论、竞品上新；
4. **研究/分析**：公开数据、周报、月度汇总；
5. **中小企业/个人**：没有技术团队，但需要网页数据。

共同点：**要的是“每天一张表”，不是“学爬虫”。**

## 3. 核心信息层级

1. 痛点：手动复制网页数据，慢、漏、网页一改就断；
2. 方案：给网址和字段，自动搭每日采集；
3. 证明：增量去重、失败通报、交付前逐条对照；
4. 门槛：零代码，在 WorkBuddy 里直接用；
5. 行动：打开专家，跑第一个任务。

不要一上来讲“技术架构/接口定位”，先讲“每天少花两小时”。

## 4. 转化漏斗

| 阶段 | 用户动作 | 内容 |
|---|---|---|
| 看到 | 刷到 15s / 45s 视频 | 痛点钩子 |
| 点开 | 打开资产页 | 产品页 + 使用示例 |
| 试用 | 在 WorkBuddy 打开 | 一键示例任务 |
| 激活 | 完成第一次采集 | 输出表格 + 验证 |
| 留存 | 第二天/第七天再用 | 定时任务、周报 |

关键：**资产页不是落地页，WorkBuddy 打开才是；视频 CTA 必须直接指向“打开”。**

## 6. 45 秒主片脚本

| 时间 | 旁白 | 画面 |
|---|---|---|
| 0–5s | 每天早上，你还在手动复制网页数据吗？ | 9:00 闹钟；浏览器标签页；Excel 空白；手在 Ctrl+C/Ctrl+V |
| 5–12s | 行情、竞品价格、招标信息、每日资讯——网页一改版，表格就断；复制粘贴，还容易漏。 | 表格错行/漏行；网页改版；红叉 |
| 12–22s | 把网址和想要的字段，交给「网站采集工程师」。它自动定位数据接口，搭好每日定时采集；增量去重、失败通报，大多数站点当天出数。 | 资产页真实截图；输入 URL；字段 chips；每日 9:00；表格自动填充 |
| 22–30s | 交付前和官网逐条对照，结果可验证；零代码。 | 左右对照；逐行打勾；代码划掉 |
| 30–38s | 行情监控、竞品价格、销售线索、每日资讯，都能变成一张自动更新的表。 | 四个场景卡快速切换，每张一个真实表格 |
| 38–45s | WorkBuddy 搜「网站采集工程师」，打开就能用。 | 资产页 + “在 WorkBuddy 打开”按钮 + 二维码/短链 |

旁白约 190 字；按 4.3 字/秒 ≈ 44s，留 1s 收尾。

## 7. 30 秒 / 15 秒剪辑

30 秒：
0–4 钩子；4–10 痛点；10–20 方案；20–26 证明；26–30 CTA。  
去掉“四个场景”，保留一个最强场景（竞品价格/每日行情）。

15 秒：
0–3 “每天手动复制网页数据？”  
3–7 “把网址和字段交给它”  
7–12 “自动搭每日采集，当天出表”  
12–15 “WorkBuddy 搜「网站采集工程师」”。

## 8. 分镜与素材

| 镜头 | 画面 | 素材 |
|---|---|---|
| S1 | 手动复制/漏行/改版 | 实拍或屏幕录制；可用现有 Excel/浏览器 |
| S2 | 资产页真实截图 | 当前分享页截图（已有） |
| S3 | 输入 URL、字段、时间 | WorkBuddy 真实录屏优先；没有则抽象 UI，标注“流程示意” |
| S4 | 表格自动填充 | 真实输出表格；脱敏 |
| S5 | 官网 vs 结果逐条对照 | 真实对比；敏感数据打码 |
| S6 | 场景卡 | 4 个真实任务截图，不虚构客户 |
| S7 | CTA | 资产页 + 打开按钮 + 二维码 |

**优先要真实录屏。** 产品视频的可信度来自“真的点开、真的出表”，不是卡片动画。

## 11. 指标

先设学习目标，不承诺增长数字：

| 指标 | 怎么看 |
|---|---|
| 资产页打开 | 分享链接/二维码来源 |
| WorkBuddy 打开 | 按钮点击/使用量变化（基线 131） |
| 首次任务完成 | 新用户是否跑通一个采集 |
| 7 日留存 | 第二周是否继续用 |
| 内容效率 | 哪个钩子带来最多打开/激活 |

## 12. 合规与边界

- 只采集公开页面或用户有权访问的数据；
- 遵守目标网站条款与 robots；
- 不宣称“任何网站都能抓”、不承诺绕过登录/付费墙/反爬；
- 案例数据脱敏；不虚构客户；
- “大多数站点当天出数”来自产品页表述，不扩写成“全部”。
