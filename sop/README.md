# sop/ · 标准作业流程

> 一类视频一份 SOP：从选题到交付的顺序、参数、时间预算、质量门禁。公共步骤引用 `knowledge/工作流/`，不重复写。

## 怎么选 SOP（4 个问题）

1. **形态**：口播 / 混剪 / 切片 / Vlog / 教程 / 访谈 / 宣传片 / 数据动画？
2. **平台与画幅**：竖屏 9:16 还是横屏 16:9？目标平台是哪个？
3. **素材条件**：实拍 / 录屏 / 素材库 / 纯图表？有没有真人出镜？
4. **自动化预期**：全手动精剪，还是批量化、模板化、脚本化？

## 路由表

| 形态 | 典型场景 | 时长 | 画幅 | 素材门槛 | 自动化潜力 | SOP |
|---|---|---|---|---|---|---|
| 口播知识 | 知识分享、观点、干货 | 30–180s | 9:16 / 16:9 | 低：手机 + 麦克风 | 中：字幕、粗剪、包装可脚本化 | [short-oral-knowledge](short-oral-knowledge.md) |
| 混剪卡点 | 情绪、燃向、宣传混剪 | 15–60s | 9:16 | 中：需大量可用镜头 | 高：卡点、转场、批量模板 | [short-montage-beat](short-montage-beat.md) |
| 直播切片 | 直播高光、带货片段 | 15–90s | 9:16 | 低：有录播源 | 高：转写、找高光、切分 | [short-live-clip](short-live-clip.md) |
| Vlog | 生活、旅行、日常记录 | 3–15min | 16:9 / 9:16 | 中：多机位/多场景素材 | 中：粗剪、配乐、字幕 | [short-vlog](short-vlog.md) |
| 教程长视频 | 软件教学、知识课程 | 5–30min | 16:9 | 中：录屏 + 讲解 | 中：步骤标记、章节、字幕 | [long-tutorial](long-tutorial.md) |
| 访谈 / 播客 | 对谈、播客视频化 | 20–120min | 16:9 | 高：双机位 + 好收音 | 中：多机位切换、转写、剪辑决策 | [long-interview-podcast](long-interview-podcast.md) |
| 产品宣传片 | 品牌 / 产品发布 | 30–120s | 16:9 / 9:16 | 高：精拍或高质量素材 | 中：模板化包装、批量版本 | [long-promo](long-promo.md) |
| 数据可视化动画 | 数据解读、报告视频 | 30–180s | 16:9 / 9:16 | 低：数据 + 图表 | 高：代码生成、参数化 | [long-data-animation](long-data-animation.md) |

> 找不到匹配：先看最接近的 SOP 的「变体」节；仍不匹配再新建（见下）。

## 通用交付规格（速查）

| 项 | 短视频 | 长视频 |
|---|---|---|
| 画幅 | 1080×1920（9:16） | 1920×1080（16:9） |
| 帧率 | 25 / 30 fps | 25 / 30 / 60 fps |
| 视频 | H.264 High，VBR 8–16 Mbps | H.264 High，VBR 6–12 Mbps |
| 音频 | AAC 48 kHz，-14 LUFS | AAC 48 kHz，-16 LUFS |
| 字幕 | 烧录（平台无自动字幕时） | 外挂 SRT / 章节 |
| 封装 | .mp4 | .mp4 / ProRes 母版另存 |

详细参数与平台差异见 [交付规格模板](../templates/交付规格.md) 与 [平台规格条目](../knowledge/工作流/platform-specs.md)。

## 通用质量门禁

- 前 3 秒钩子成立（短视频）/ 前 30 秒价值承诺（长视频）
- 规格与模板一致，音画同步，无黑帧 / 爆音
- 字幕无错别字、不出安全区
- 事实与版权合规
- 过 [QC 清单](../templates/QC清单.md)

## 新增一条 SOP

1. 复制 [SOP 模板](../templates/SOP.md) 到 `sop/<slug>.md`。
2. 在路由表登记；在 [分类体系](../docs/知识分类体系.md) 的形态表登记。
3. 必备节填全；参数给出具体值；至少写 3 条「常见问题」。
4. 关联对应 `knowledge/` 条目与技能。
5. 跑 `python3 scripts/build_index.py` + `python3 scripts/validate.py`。
