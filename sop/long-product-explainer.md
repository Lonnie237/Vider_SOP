# 产品功能 / 官网说明视频 · 录屏 + 包装 SOP

> 读者：要为公司官网、产品功能、SaaS onboarding 做一条 60–180 秒说明视频的人或执行 Agent。目标：**初次剪辑即可上线**，讲清「能帮我做什么」。

## 适用 / 不适用

| 适用 | 不适用（改用什么） |
|---|---|
| 官网首页/落地页说明、产品功能更新、客户 walkthrough | 品牌形象片：[产品宣传片 SOP](long-promo.md) |
| 有可操作的 Web/App/桌面界面 | 软件教学长视频：[教程 SOP](long-tutorial.md) |
| 60–180s，3–5 个功能点 | 纯数据展示：[数据动画 SOP](long-data-animation.md) |
| 真实操作可信度优先 | 无产品可录：用动画/图文（Remotion/代码视频）替代 |

## 交付规格

| 项 | 主规格 | 变体 |
|---|---|---|
| 分辨率 | 1920×1080（16:9） | 1080×1920（竖屏 30–60s） |
| 帧率 | 30 fps（录屏 60fps 采集） | 平台要求 25/60 |
| 视频 | H.264 High，VBR 8–12 Mbps | 屏幕文字多取上限 |
| 音频 | AAC 48 kHz 192 kbps，-14 LUFS | 官网无声自动播放：无旁白 + 字幕 |
| 字幕 | 烧录或外挂 SRT | 多语言外挂 |
| 封装/命名 | .mp4，`<产品>-demo-v1-<date>.mp4` | 附封面/缩略图 |
| 时长 | 60–180s | 官网 60–90s；客户 120–180s |

## 前置准备

- 产品访问：测试账号、干净浏览器 profile（无书签/插件/通知）、测试数据。
- 脚本：目标用户/问题/3–5 功能点/CTA；每步一句旁白。
- 工具：OBS 或系统录屏；Playwright/DemoDSL（可选自动化）；NLE 或 ffmpeg；TTS。
- 素材：Logo、品牌色、字体、可商用 BGM、片头/片尾模板。
- 立项：填 [项目 Brief](../templates/项目Brief.md)；分镜用 [分镜表](../templates/分镜表.md)；规格用 [交付规格模板](../templates/交付规格.md)。

## 流程总览（90 秒成片，单人）

| 阶段 | 产出 | 时间预算 |
|---|---|---|
| S0 Brief 与脚本 | 脚本 + 功能点 | 1.0h |
| S1 分镜/操作清单 | 每步页面/操作/镜头/旁白 | 0.5h |
| S2 录屏/采集 | 原始录屏 + 测试数据 | 1.0h |
| S3 粗剪 | 按旁白定时间轴 | 0.5h |
| S4 精剪与标注 | 放大/聚光/箭头/光标 | 1.5h |
| S5 配音 | 旁白 + 响度 | 0.5h |
| S6 字幕 | SRT / 烧录 | 0.3h |
| S7 包装 | 片头/片尾/Logo/BGM | 0.5h |
| S8 导出 + QC | 成片 + QC 记录 | 0.5h |
| 合计 | — | 约 6.3h |

## 分阶段操作

### S0 Brief 与脚本

- 结构：钩子（0–5s 给结果）→ 问题（5–15s）→ 演示（3–5 步）→ 证据/对比 → CTA。
- 每步一句旁白（4–6 字/秒）；不要念功能清单，讲「用户得到什么」。
- 先写 3 版开头，选「结果前置」那版。

### S1 分镜/操作清单

| # | 页面 | 操作 | 镜头 | 旁白 | 标注 |
|---|---|---|---|---|---|
| 1 |  | 点击/滚动/输入 | 全屏/放大 |  |  |

- 每步只做一件事；预计 3–6s。
- 标出需要打码/隐藏的区域（邮箱、密钥、客户名）。

### S2 录屏/采集

- 1080p/60fps 采集；窗口固定尺寸，隐藏书签栏、通知、个人信息。
- 鼠标移动慢、点击前停顿 0.3s；避免无意义晃动。
- 每个功能点单独录一条，方便粗剪；录完立刻备份。
- 自动化可选：Playwright/DemoDSL 按 YAML 步骤截图/录屏；先 `validate/probe/storyboard/estimate` 再渲染。

### S3 粗剪（音频驱动）

- 先按旁白定时间轴，删等待、加载、误操作、空白页。
- 每步 3–6s；连续 3s 无信息就砍。
- 保留真实操作手感，不要全加速。

### S4 精剪与标注

- 放大关键区域 1.2–1.5×，加聚光灯/箭头/编号；光标高亮或点击波纹。
- 转场克制：硬切为主，重要节点用 0.2–0.3s 叠化。
- 字幕不遮挡按钮/菜单，放底部安全区或上移。

### S5 配音

- TTS 或真人；语速 4–6 字/秒；每步旁白与画面对齐。
- 响度 -14 LUFS，真峰值 ≤ -1.5 dBTP。

### S6 字幕

- 按成片时间轴生成；每行 ≤ 16 字（16:9 可 20 字），最多 2 行。
- 官网无声播放版本：字幕承担全部信息，关键步骤用画面标注补足。

### S7 包装

- 片头 1–2s（Logo + 一句话），片尾 2–3s（CTA/网址）。
- BGM -18～-24dB，旁白处 ducking；操作音效克制。

### S8 导出 + QC

- H.264 High 8–12Mbps；AAC 192k；faststart。
- QC：规格、响度、黑帧、隐私、字幕、前 5 秒钩子。

## 参数速查

| 场景 | 参数 | 值 |
|---|---|---|
| 时长 | 官网 / 客户 | 60–90s / 120–180s |
| 功能点 | 数量 | 3–5 个 |
| 每步 | 时长 | 3–6s |
| 放大 | 倍率 | 1.2–1.5× |
| 录屏 | 采集 | 1080p / 60fps |
| 旁白 | 语速 | 4–6 字/秒 |
| 响度 | 交付 | -14 LUFS |
| 码率 | 交付 | 8–12 Mbps |

## 质量门禁（QC）

- [ ] 前 5s 能让目标用户说出「这帮我做什么」
- [ ] 每个功能点都有「操作 + 可见结果」
- [ ] 无连续 3s 无信息；无鼠标乱晃/等待
- [ ] 界面文字在手机尺寸可读；字幕不挡 UI
- [ ] 无真实邮箱/密钥/客户数据；该打码处已打码
- [ ] 规格/响度/黑帧/命名通过 qc-deliver
- [ ] 官网版本：静音播放也能看懂

## 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 前 5 秒没人看懂 | 从公司介绍讲起 | 改成结果/痛点前置 |
| 界面文字糊 | 全屏录制 + 低码率 | 放大关键区域 + 提高码率 |
| 滚动卡顿 | 30fps 采集 | 60fps 采集，交付转 30 |
| 隐私泄露 | 真实数据/书签 | 测试账号 + 打码 + 干净 profile |
| 节奏拖沓 | 等待/加载没剪 | 按旁白时间轴删停顿 |
| 字幕挡操作 | 字幕位置固定 | 按画面内容上移/加底框 |

## 可自动化环节

| 环节 | 方式 | 工具 |
|---|---|---|
| 操作采集 | DSL/Playwright 脚本 | DemoDSL / Playwright |
| 旁白/字幕 | TTS + 转写对齐 | edge-tts / WhisperX |
| 片头片尾/动效 | 代码模板 | Remotion / ffmpeg |
| 导出/QC | 脚本 | ffmpeg + qc-deliver |

## 变体（平台 / 时长 / 素材条件）

| 变体 | 差异 |
|---|---|
| 官网自动播放 | 静音 + 字幕 + 更短（30–60s） |
| 竖屏 9:16 | 界面放大裁切，字幕安全区上移 |
| 客户交付 | 附功能清单、字幕、封面、不同语言版本 |
| 无录屏条件 | 用截图 + 动效/动画替代，标注「示意」 |

## 复盘与改进

- 本机尚无真实产品录屏端到端实测；DemoDSL/Playwright 未安装，相关步骤标 [待确认]。
- 上线后回填：首 5 秒留存、官网转化、客户反馈；把有效开头写回 [钩子方法论](../knowledge/方法论/hooks-retention.md)。
- 常见返工点：开头、节奏、隐私打码、字幕遮挡。
