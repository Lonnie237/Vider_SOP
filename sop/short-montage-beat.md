# 混剪卡点 · 情绪向卡点混剪 SOP

> 读者：要做燃向 / 情绪向竖屏混剪的人或执行 Agent。目标：15–60s 成片，切点跟节拍走，情绪有起伏，不靠堆特效。

## 适用 / 不适用

| 适用 | 不适用（改用什么） |
|---|---|
| 情绪、燃向、氛围向混剪；15–60s 竖屏 | 需要讲清一个知识点 → [口播知识](short-oral-knowledge.md) |
| 影视 / 游戏 / 运动 / 城市 / 产品素材混剪 | 素材少于 30 个可用镜头 → 拉长单镜，改成 Vlog 式叙事 |
| 已有可商用音乐、BPM 明确 | 需要讲完整故事、有对白采访 → [Vlog](short-vlog.md) |
| 促销 / 活动预告的竖版切片 | 长直播原片取一段 → [直播切片](short-live-clip.md) |

## 交付规格

| 项 | 主规格 | 变体 |
|---|---|---|
| 分辨率 / 画幅 | 1080×1920（9:16） | 1920×1080 横版（B 站 / YouTube，响度改 -16 LUFS） |
| 帧率 | 30 fps 恒定 | 素材 60 fps 混入时统一到 30 fps，避免卡点漂移 |
| 视频编码 / 码率 | H.264 High、level 4.2、VBR 8–16 Mbps（目标 12 Mbps） | 切点密集的片子码率取上限 14–16 Mbps |
| 音频 | AAC 48 kHz 立体声 192 kbps、-14 LUFS ±1、真峰值 ≤ -1.5 dBTP | 音乐类混剪不得为响度把鼓点压平 |
| 字幕 | 大字标题烧录，正文可省（信息量低） | 金句 / 歌词式字幕走 Pillow overlay |
| 封装 / 命名 | .mp4 / `montage-<主题>-<BPM>-v<n>-<日期>.mp4` | 母版留 ProRes 422 |
| 时长 | 15–60s，主节奏在 3s 内进入 | 15–30s 适合信息流，45–60s 适合品牌情绪片 |

## 前置准备

- 素材：可用镜头数 ≥ 目标镜头数 ×3（例：30s 片子按 60 镜规划，需 180 个可用镜头）；统一到 1080p30 或更高、无严重抖动。
- 音乐：可商用授权，BPM 已知（120–150 适合燃向），前奏 ≤3s 进入主节奏；导出 WAV 供打点。
- 工具：NLE（Premiere Pro / DaVinci Resolve / 剪映专业版）；本机 ffmpeg 9.0.2 用于波形图、规格校验与导出。
- 节拍检测：本机未装 librosa / aubio，节拍靠剪映「自动踩点」或 NLE 手动打标记；ffmpeg 只做波形可视化辅助。

## 流程总览（阶段 × 产出 × 时间预算）

> 基准：3 分钟（180s）成片、单人操作、素材已就位。换算：目标时长 T 秒 → 可变工时 ×（T/180），固定工时不变；总预算 = 固定 + 可变 ×（T/180）。

## 分阶段操作

### S0 主题与情绪曲线

- 一句话主题：只写一个情绪落点（燃 / 治愈 / 紧迫 / 怀念），全片不为第二个情绪分心。
- 情绪曲线四段（时长按占比）：开场冲击 0–3s（0.2–0.5s/镜，每拍切）→ 铺垫（0.8–1.5s/镜，每 2 拍）→ 爆发（0.3–0.6s/镜，每 0.5–1 拍）→ 收尾（1–2s/镜 + 定格或黑场）。
- 输出：情绪曲线表「段落 | 起止占比 | 单镜时长 | 切点密度 | 音乐位置」。

### S1 选乐与 BPM 分析

- 每拍时长 = 60 / BPM；镜头数估算 = 时长 ÷（每拍 × k），k 为每镜拍数（燃向 0.5–1.5）。

| BPM | 每拍 | 每 0.5 拍 | 每 2 拍 | 30s 镜头数（k=1） |
|---|---|---|---|---|
| 100 | 0.60s | 0.30s | 1.20s | 50 |
| 120 | 0.50s | 0.25s | 1.00s | 60 |
| 140 | 0.43s | 0.21s | 0.86s | 70 |
| 150 | 0.40s | 0.20s | 0.80s | 75 |

- 打点：剪映「音频 → 自动踩点 → 踩节拍 II」；Premiere 播放时按 `M` 加标记；达芬奇时间线按 `M`，再把强拍改成红色标记。
- 波形辅助（本机实测 2026-11-03，输出 PNG 供对照）：

```bash
ffmpeg -hide_banner -y -i music.wav -filter_complex "showwavespic=s=1920x400:colors=white" -frames:v 1 music_wave.png
```

### S2 素材收集与筛选

- 硬门槛：分辨率 ≥1080p、可读、无穿帮；单个可用镜头 ≥2s（短于 1s 的只能做闪切）。
- 打标：按景别（远 / 中 / 近 / 特）和情绪（起 / 承 / 转 / 合）上颜色标签，方便按卡点表检索。
- 统一：所有素材统一到 1080p30 时间线；帧率不一致先转，再进时间线，避免切点漂移。
- [待确认] 素材授权范围（影视 / 游戏片段）需按发布平台与版权方要求逐条确认，不要默认可用。

### S3 卡点表

- 用 [分镜表](../templates/分镜表.md) 的混剪变体：`时间码 | 音乐位置（小节/拍） | 画面内容 | 时长 | 转场`。
- 先定 8–12 个锚点镜头落强拍（开场冲击、副歌第一拍、收尾），其余按空间填充；锚点定错会整片「差半拍」。
- 每个锚点写清「观众看到什么 + 听到什么」，避免只写素材编号。

### S4 粗排

- 按卡点表顺序铺镜头，只对强拍，不调速度与转场。
- 静音看一遍：切点节奏是否成立；再把音乐打开，检查画面是否被音乐「推着走」。
- 常见返工点：先精剪第一段再往后铺 → 后面节奏全乱；先铺满再统一精剪。

### S5 精剪（切点 / 变速 / 转场）

- 切点：强拍硬切，弱拍可叠 1–2 帧过渡；闪白 / 闪黑只做 2–3 帧，多了像故障。
- 变速：50–200% 区间；加速用于铺垫段，减速用于爆发后的定格；速度斜坡每段 ≤1 次。
- 转场：硬切 ≥80%；遮罩 / 缩放转场全片 ≤3 个，且只放在段落转换处。

### S6 声音设计

- 鼓点强化：切点加 whoosh / impact / riser，电平 -18 ~ -12 dB，只强化强拍，不要每个切点都加。
- 音乐：压缩比 2:1–3:1，人声或旁白出现时 duck -3 ~ -6 dB；音乐自身峰值 ≤ -6 dBFS。
- 响度：目标 -14 LUFS、真峰值 -1.5 dBTP；先测量再归一（本机实测命令）：

```bash
ffmpeg -hide_banner -nostats -i mix.wav -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null - 2>&1 | tail -12
```

### S7 调色与统一

- 先统一：白平衡、曝光、对比度让所有镜头「像同一天拍的」；再上风格。
- 风格：高对比 + 青橙或低饱和冷调，选一个；LUT 强度 40–70%，不要 100%。
- 不逐镜大调；差异大的镜头优先换素材，而不是硬调。

### S8 包装

- 标题 3–8 字，前 3s 上屏、停留 2s；放在画面上 1/4，避开平台顶部 UI 与底部字幕区。
- 花字 2–4 个：只在情绪转折处；不逐镜加字。
- 片尾 1–2s 定格 + CTA，不做长片尾。

### S9 导出

- 命令行（本机实测 2026-11-03：1080×1920 → H.264 High / 12.2 Mbps / AAC 48 kHz，退出码 0）：

```bash
ffmpeg -hide_banner -y -i montage_cut.mp4 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,setsar=1" -c:v libx264 -preset slow -profile:v high -level 4.2 -pix_fmt yuv420p -r 30 -b:v 12M -maxrate 16M -bufsize 24M -c:a aac -b:a 192k -ar 48000 -ac 2 -movflags +faststart out.mp4
```

- 自查：`ffprobe -v error -show_entries format=bit_rate -show_entries stream=profile,width,height,r_frame_rate -of compact out.mp4`。

## 质量门禁（QC）

- [ ] 规格：1080×1920 / 30 fps / H.264 High / 8–16 Mbps / AAC 48 kHz 192k / .mp4
- [ ] 成片时长 15–60s；主节奏在 3s 内进入
- [ ] 切点与节拍对齐：抽 10 个切点，逐个对波形峰值，偏差 ≤2 帧
- [ ] 情绪曲线成立：开场冲击 → 铺垫 → 爆发 → 收尾，可指认段落边界
- [ ] 响度 -14 LUFS ±1、真峰值 ≤ -1.5 dBTP；无爆音、无削波
- [ ] 画面统一：无跳色、无穿帮、无糊片；相邻镜头景别不重复
- [ ] 无版权风险：音乐与素材授权可追溯
- [ ] 手机竖屏实机预览 ≥1 次，重点看切点是否「卡在拍上」

## 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 整体「差半拍」 | 音乐起点未对齐 / 标记错拍 | 重新对齐音乐第 1 拍，全片标记整体平移 |
| 切点很密但不好看 | 只卡拍不看画面内容 | 强拍放有动作方向或情绪峰的镜头，弱拍才放填充 |
| 素材不够，重复用镜 | 可用镜头 < 目标×2 | 降时长或降 k 值（拉长单镜），不要靠重复镜头凑 |
| 导出后切点变糊 | 素材帧率与时间线不一致 | 统一 30 fps 后再剪；避免变速后二次转码 |
