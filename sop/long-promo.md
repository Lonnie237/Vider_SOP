# 产品宣传片 · SOP

> 读者：第一次做品牌 / 产品宣传片的人或执行 Agent。目标：30–120s 内讲清一个卖点、拿出证据、给明确 CTA，并一次交付横竖两版。

## 适用 / 不适用

| 适用 | 不适用（改用什么） |
|---|---|
| 产品发布、官网首屏、投放素材、众筹 / 招商片 | 长教程 / 功能演示：用 `sop/long-tutorial` |
| 30–120s，单一卖点 + 证据 + CTA | 访谈 / 品牌故事长片：用 `sop/long-interview-podcast` |
| 需要横屏官网版 + 竖屏投放版 | 纯数据解读动画：用 `sop/long-data-animation` |

## 交付规格

| 项 | 横屏主规格（16:9） | 竖屏变体（9:16） |
|---|---|---|
| 分辨率 / 帧率 | 1920×1080 / 30fps 恒定 | 1080×1920 / 30fps 恒定 |
| 视频编码 | H.264 High，VBR 平均 9Mbps / 峰值 12Mbps（6–12Mbps） | H.264 High，VBR 平均 12Mbps / 峰值 16Mbps（8–16Mbps） |
| 音频 | AAC 48kHz 立体声 192kbps，-16 LUFS（±1） | AAC 48kHz 192kbps，-14 LUFS（±1） |
| 字幕 / 字卡 | 字卡直接烧录（NLE 出片）；旁白字幕外挂 SRT | 字卡烧录；字号更大、底部留 15% 安全区 |
| 封装 / 命名 | .mp4（`+faststart`）；`<产品>-<时长>-<画幅>-v<版本>-<YYYYMMDD>.mp4` | 同左，画幅标 `9x16` |
| 时长 | 30 / 60 / 90 / 120s 版本按投放位选 | 15 / 30 / 60s 为主 |
| 附交付 | 无字幕 clean 版（NLE 单独导出）、无音轨版、封面帧 | 同左，另加竖屏封面 |

## 前置准备

- 素材：产品实拍（多角度 + 微距）、使用场景、UI 录屏、数据 / 客户证言、品牌资产（logo / 字体 / 色值）；工具：DaVinci Resolve 或 Premiere 剪辑，After Effects 或 Remotion 动效，FFmpeg 9.0.2 转码与多版本导出。
- 授权：音乐 / 音效、字体、素材库、肖像、客户 logo 使用许可，逐项登记来源与到期日。
- 立项：填 [项目Brief](../templates/项目Brief.md)，明确**唯一受众 + 唯一卖点 + 唯一 CTA**，分镜用 [分镜表](../templates/分镜表.md)；收集 3 条同品类参考片，标注「学什么 / 不学什么」。

## 流程总览（阶段 × 产出 × 时间预算）

以 **60s 成片 + 横竖两版** 估算。

| 阶段 | 产出 | 时间预算 |
|---|---|---|
| S0 卖点提炼 | 卖点一句话 + 3 条证据 + CTA | 2h |
| S1 脚本 / 卖点结构 | 30/60/120s 三版文字脚本 | 3h |
| S2 分镜 | 镜头表（画面 / 台词 / 时长 / 素材） | 3h |
| S3 素材 | 实拍 + 录屏 + 图形素材 + 授权清单 | 1–3 天 |
| S4 粗剪 | 结构版：痛点 → 方案 → 证据 → CTA | 4h |
| S5 精剪 | 节奏版（卡点 / 镜头时长 / 首帧） | 6h |
| S6 动效包装 | 字卡 / 数据动效 / UI 演示动画 | 1–2 天 |
| S7 声音 | 旁白 + 音乐 + 音效混音 | 4h |
| S8 调色 | 品牌色调统一 | 4h |
| S9 多版本导出 | 横屏 / 竖屏 / 无字幕 / 无音轨 + 封面 | 2h |
| S10 QC | QC 记录 + 平台合规检查 | 1h |

## 分阶段操作

### S0 卖点提炼

- 判断标准：能用一句话说清「给谁、解决什么、为什么信」；说不清就是卖点没定，不要开拍。
- 输出：卖点一句话 + 3 条可验证证据（数据 / 演示 / 客户证言）+ 1 个行动号召（CTA，如试用 / 预约 / 购买）。反例：把功能列表当卖点，一条片子塞 5 个卖点。

### S1 脚本与卖点结构

**痛点 → 方案 → 证据 → CTA** 四段式，按总时长分配：

| 段落 | 30s 版 | 60s 版 | 120s 版 | 内容要求 |
|---|---|---|---|---|
| 痛点 | 0–5s | 0–10s | 0–20s | 观众正在经历的具体场景，不要抽象概念 |
| 方案 | 5–15s | 10–30s | 20–55s | 产品如何解决，出现产品本体 |
| 证据 | 15–25s | 30–50s | 55–100s | 数据 / 演示 / 客户证言，至少 1 条可核 |
| CTA | 25–30s | 50–60s | 100–120s | 明确动作 + 停留 ≥2s |

- 30s 版只保留「痛点 + 方案 + CTA」，证据压成一句字幕；旁白按 4–5 字/秒估算字数，字卡每屏 ≤12 字。
- 输出：三版文字脚本（30 / 60 / 120s），每句标时长与对应画面。

### S2 分镜

- 一行一个镜头：画面、台词 / 字卡、景别、时长、素材文件（模板见 [分镜表](../templates/分镜表.md)）；首帧就是最抓人的画面（产品高光 / 使用瞬间 / 反差场景），不要 logo 开场。
- 镜头数量：30s ≈ 20–35 个、60s ≈ 35–60 个，平均 1.5–3s；转场以硬切为主，字卡 / 图形过渡 0.2–0.4s。

### S3 素材

- 实拍清单按分镜逐条拍，每个镜头至少 2 条可用素材；UI / 数据录屏按 1920×1080 以上录制留放大空间，产品图用官方渲染图。
- 素材命名 `<日期>-<场景>-<序号>`，授权清单与素材同目录。

### S4 粗剪

- 只搭结构：四段式各就位、配参考音乐、不抠细节；完成标准是不看画面只听声音也能听懂卖点，时长偏差 <10%。

### S5 精剪（节奏）

- 节奏：按音乐重拍切镜，强拍放产品高光 / 字卡，镜头平均 1.5–3s；首 3 秒直接给痛点或结果。
- 字卡每屏 ≤12 字、停留 ≥1.5s，关键信息配图标或数字；常见返工点：切太碎像 PPT、音乐压旁白、CTA 出现太晚。

### S6 动效包装

- 字卡 / 数据动效：AE 或 Remotion，入出场 0.3–0.6s，同一套缓动曲线贯穿全片；UI 演示用录屏 + 局部放大 + 高亮，不用花哨 3D 转场。
- 品牌元素：logo 安全区 ≥ 画面宽 5%，色值 / 字体从品牌规范取；动效预合成（pre-comp）单独命名版本，方便客户改文案。

### S7 声音

- 旁白：横屏成片 -16 LUFS、竖屏 -14 LUFS，语速 4–5 字/秒、句尾降调；音乐选可商用授权曲，卡点对齐剪辑点且比旁白低 10–15dB。
- 音效：转场、点击、产品出现各给一个，不要每个镜头都加。

### S8 调色

- 品牌色优先：先保证产品颜色准确（白平衡 / 肤色）再做风格化，不同场景肤色与产品色一致；参考 `kb/color-grading` 的一级校正，交付前用同一显示器 / 播放器抽检。

### S9 多版本导出

- 横屏版直接从 16:9 时间线导出；竖屏版**重新构图**（改机位 / 换景别 / 重排字卡），不是把横屏裁成竖屏。
- 竖屏安全区：上下各留 15%，重要信息避开右侧平台按钮区。

```bash
# 横屏交付：1080p30 / H.264 High / VBR 9M（峰值 12M）/ AAC 192k / -16 LUFS
ffmpeg -y -i promo_master_16x9.mov \
  -c:v libx264 -preset slow -profile:v high -level 4.1 \
  -b:v 9M -maxrate 12M -bufsize 18M -pix_fmt yuv420p -r 30 \
  -af "loudnorm=I=-16:TP=-1.5:LRA=11" \
  -c:a aac -b:a 192k -ar 48000 -ac 2 \
  -movflags +faststart promo-60s-16x9-v1.mp4
```

```bash
# 竖屏交付：1080×1920 / 30fps / VBR 12M（峰值 16M）/ AAC 192k / -14 LUFS
ffmpeg -y -i promo_master_9x16.mov \
  -c:v libx264 -preset slow -profile:v high -level 4.2 \
  -b:v 12M -maxrate 16M -bufsize 24M -pix_fmt yuv420p -r 30 \
  -af "loudnorm=I=-14:TP=-1.0:LRA=11" \
  -c:a aac -b:a 192k -ar 48000 -ac 2 \
  -movflags +faststart promo-30s-9x16-v1.mp4
# 无音轨版（平台静音自动播放 / 客户自行配乐）：只删音频流，视频不重编码
ffmpeg -y -i promo-30s-9x16-v1.mp4 -c copy -an promo-30s-9x16-mute.mp4
```

- 封面：从正片抽帧或单独设计，横竖各一张；首帧 / 封面不要带平台 UI 遮挡。

### S10 QC

按 [QC 清单](../templates/QC清单.md) 逐项过；额外检查品牌规范（logo 尺寸、色值、字体授权）与广告合规（「最」「第一」等绝对化用语）。

## 参数速查

| 场景 | 参数 | 值 |
|---|---|---|
| 横屏 | 分辨率 / 码率 / 响度 | 1920×1080 / VBR 9M（峰值 12M） / -16 LUFS |
| 竖屏 | 分辨率 / 码率 / 响度 | 1080×1920 / VBR 12M（峰值 16M） / -14 LUFS |
| 镜头 | 平均时长 | 1.5–3s；首 3 秒 2–4 个镜头 |
| 字卡 / CTA | 字数 / 停留 | 字卡 ≤12 字 / ≥1.5s；CTA 最后 5–10s 出现、停留 ≥2s |
| 旁白 / 音乐 | 语速 / 相对电平 | 4–5 字/秒；音乐比旁白低 10–15dB |

## 质量门禁（QC）

- [ ] 单一卖点清晰，观众 5s 内知道「这是什么、给谁用」
- [ ] 四段式完整：痛点 / 方案 / 证据 / CTA，缺一不可
- [ ] 证据可核（数据有来源、证言有授权、演示是真机）；首 3 秒无 logo 开场，有明确钩子
- [ ] 横竖两版都重新构图，竖屏主体 / 字卡不出安全区；规格达标（ffprobe 核对）
- [ ] 音响平衡：旁白清晰、音乐不压人声、无爆音
- [ ] 品牌规范：logo 比例、色值、字体授权、无错别字
- [ ] 授权齐全：音乐 / 素材 / 肖像 / 客户 logo
- [ ] 平台合规：无绝对化用语、无未标注广告

## 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 卖点太多、观众记不住 | 把功能列表当脚本 | 砍到 1 个卖点 + 3 条证据，其余进官网详情页 |
| 竖屏版像裁出来的 | 直接 16:9 裁 9:16，主体出画 | 竖屏重新分镜 / 重排字卡，必要时补拍竖构图 |
| 导出后颜色变了 | 色彩空间 / 播放器不一致 | 全流程 Rec.709，交付前在目标平台预览 |
| 客户反复改版本 | 无版本管理、口头改需求 | 文件名带版本，需求变更写进 Brief / 变更记录 |

## 变体（平台 / 时长 / 素材条件）

| 变体 | 差异 |
|---|---|
| 官网 / 客户交付 | 16:9 为主，附 ProRes 422 母版、无音轨版、无字幕版、封面；按合同交付分辨率 |
| YouTube | 16:9；官方建议 1080p 30fps SDR 上传 8Mbps；前 5s 可跳过，钩子必须前置 |
| B站 | 16:9；标题 / 封面决定点击，片尾加三连引导；长版本可放简介补充参数 |
| 抖音 / 视频号 | 9:16；1080×1920 / 8–16Mbps / -14 LUFS；前 3 秒钩子，字幕 64–72px，CTA 用平台组件 |

## 复盘与改进

- 实测记录（2026-11-03，ffmpeg 9.0.2）：横屏 1080p30 VBR 9M 与竖屏 1080×1920 VBR 12M 导出、-16 / -14 LUFS loudnorm 均在本机跑通（合成样片）；本机无 libass，字卡由 NLE 烧录。待优化：Remotion 只做了最小示例、未接真实品牌模板，投放版未做 A/B 数据回流。
