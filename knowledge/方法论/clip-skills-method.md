# 剪辑决策方法 · 判断与软件分离、音频驱动、黑场交回

> 来源：[appergb/ClipSkills](https://github.com/appergb/ClipSkills)（MIT）。本文只提炼可迁移的决策框架，不转载课程内容；经验性阈值标 [推断]。

## 一句话定位

把剪辑从「点哪个按钮」重写成「在什么情况下、依据什么、做什么决定、输出什么」：判断逻辑与软件操作分离，先有声音骨架再贴画面，机器负责可复现部分，审美与黑场交回人。

## 适用场景

- 口播、访谈、Vlog、录屏、产品演示的初剪与精剪。
- 给 Agent 或初级剪辑者一套可执行决策规则，而不是软件教程。
- 不适用：纯模板化出片（用 [纯代码视频管线](../工作流/code-video-pipeline.md)）、无音轨的纯动效片。

## 原理与判断标准

1. 三种模式先判定：答疑（问方法）/ 反问（信息不足）/ 自主执行（素材与目标就绪）；信息不足时不带假设硬剪。
2. 判断与执行分离：知识（怎么剪、为什么、好坏）与软件（剪映/PR/达芬奇/FFmpeg/Remotion）分开；每个软件用独立子 Agent，避免上下文污染。
3. 音频优先：口播/访谈/Vlog 先做声音骨架（转写→气口→删废话），再贴画面。
4. 素材 A/B 分类：A-roll 主线、B-roll 补充；没分类先引导分类。
5. 黑场红线：遗留黑场/未覆盖硬切不自动裁切主轨，标注位置交回人。
6. 耗算力后置：抠像/跟踪/补帧/变速放粗剪定稿后，做完先备份。
7. taste 交回用户：Agent 清重复劳动，最终取舍由人定。

## 可操作步骤（音频驱动主流程）

1. 准备：确认软件、画幅、视频类型、时长目标；素材按 A/B 归类。
2. 取音频：提取主音轨 → 带时间戳转写（WhisperX 等）→ 得到断点（气口/句界）与切入点。
3. 精剪声骨：按句删卡顿、口误、重复、长停顿；保留自然呼吸。
4. 提主逻辑：逐段标注「这一句在讲什么」，形成叙事主线。
5. 贴画面：按字幕语义匹配 B-roll；对齐节奏、成组使用、遮蔽硬切、不重复、静音处理。
6. 声音与进阶：BGM 卡点、J/L-cut、侧链让位；按需关键帧/变速/抠像/跟踪。
7. 调色与导出：非破坏性调色，按平台规格导出；demo 与 export 分离。
8. 收尾：标出无法覆盖的黑场/空缺，交回用户；输出成片 + 工程 + 问题清单。

## 参数与阈值

| 参数 | 推荐值 | 依据 |
|---|---|---|
| 口播语速 | 4–6 字/秒 | [推断] 知识类口播舒适区 |
| 单镜头时长 | 2–5s（信息密集 1–2s） | [推断] 与信息密度匹配 |
| 气口处理 | 删长停顿与废话，保留自然换气 | [推断] 过度剪切失去人味 |
| B-roll 覆盖 | 每 20–30s 至少 1 个视觉变化 | [推断] 防视觉疲劳 |
| 粗剪到精剪顺序 | 声骨 → 结构 → 画面 → 声音细节 → 调色 | 来源方法论 |
| 黑场处理 | 0 自动删除，全部标注交回 | 来源红线 |

## 常见反例

| 反例 | 为什么不行 | 怎么改 |
|---|---|---|
| 先铺画面再找声音 | 节奏被素材绑架，口播断裂 | 先做声音骨架 |
| 用静音检测代替内容判断 | 打字、音乐、环境声会骗过检测 | 用增强后 RMS + 转写语义判断 |
| 一上来抠像/跟踪/补帧 | 耗算力且返工成本高 | 粗剪定稿后再做 |
| Agent 自动删主轨黑场 | 可能删掉必要信息 | 标位置，交回人 |
| 同一上下文混用多套软件细节 | 参数/坐标系互相污染 | 每软件独立子 Agent |
| 把创作者经验当普适数据 | 不同品类/平台不成立 | 标 [推断] 与适用条件 |

## 验证方式

- 初剪：连续看一遍，检查每句在讲什么、是否有连续 5s 无信息。
- 声音：响度达标、无爆音、气口自然；字幕与语音对齐。
- 交付：黑场清单为零或已交回用户；导出规格与平台一致。
