# 分镜/成片核验 · Agent 能做什么、不能做什么

## 一句话定位

**分镜可以 Agent 核，成片也可以 Agent 核，但必须给「可指认的证据」：分镜表/版式卡/线框、抽帧、转录、时长/响度指标。** 不给证据就让 Agent「看片」，只会得到空话。脚本+分镜完成后，还要加一道 **E2E 连续性评审**，专抓前后错位。

## 适用场景

- 脚本、分镜、版式卡、线框、样片、成片的质量门禁。
- 没有业务老师/审片人，需要自动化 + Agent 补位。
- 不适用：需要真实学习效果、临床/法律/安全结论；这些仍需试播或人类专家。

## 原理与判断标准

### 1. 三个问题的直接回答

| 问题 | 回答 | 边界 |
|---|---|---|
| 分镜能否 Agent 核验？ | **能**：按版式卡/分镜表核对焦点、层级、安全区、镜头-目标映射、母版一致性 | 动态节奏/最终观感仍要静帧+样片 |
| 成片能否 Agent 核验？ | **能，但混合**：先机器指标（ffprobe/ebur128/抽帧/转录），再 Agent 看证据 | Agent 不能替代「看/听」与试播 |
| 脚本+分镜后有无整体审核？ | **应有**：新增 E2E 连续性评审，脚本+分镜后一次、样片/成片后一次 | 不是把 4 个阶段评审重复一遍 |

### 2. 证据边界

| 对象 | Agent 可核 | 不能只靠 Agent |
|---|---|---|
| 脚本 | 事实、目标、证据、误区、结构 | 学生真实反应 |
| 分镜/版式卡 | 镜头-目标映射、母版一致、焦点/层级/安全区、字幕/屏显重复 | 运动节奏、最终观感 |
| 线框/静帧 | 构图、焦点、溢出、安全区 | 转场/动画是否顺 |
| 成片 | 抽帧、转录、时长、字幕行数、响度、声画同步、首帧/黑帧 | 好看/好听、学习效果 |

> 原则：**Agent 评审的是「可指认的证据」，不是「感觉」。** 没有帧/转录/指标，就不让它评成片。

## 可操作步骤

### Phase A · 分镜核验（脚本+分镜后）

1. 给 Agent：脚本、分镜表、版式卡、线框/静帧。
2. 问四件事：
   - 每镜是否只服务一个结论/目标？
   - 同一母版是否结构稳定，是否连续 3 镜以上同构？
   - 焦点/安全区/字幕区是否冲突？
   - 屏显是否复述字幕或提前泄题？
3. 输出：P0（焦点不明/溢出/安全区/信息过载）、P1、verdict。
4. Lead 裁决；P0 清零才做样片。

### Phase B · 成片 QC（渲染后）

先机器，后 Agent：

1. ffprobe：时长、帧率、分辨率、音轨；
2. ffmpeg：首帧、黑帧、每 2s 抽帧 contact sheet；
3. ebur128：integrated LUFS / true peak；
4. 字幕：条数、单行字数、重叠/越界；
5. 转录/时间戳：旁白与字幕/画面锚点是否对齐；
6. Agent：只看 contact sheet + 转录 + 指标，给 P0/P1；
7. Lead 裁决；P0 清零才发布/试播。

### Phase C · E2E 连续性评审（脚本+分镜后、成片后各一次）

输入：目标-证据矩阵、脚本、分镜、版式卡、转录、contact sheet、指标。

| 检查 | 问题 |
|---|---|
| 目标覆盖 | 每条目标是否有脚本段落、分镜、证据三处落点？ |
| 证据独立 | 后测题是否只考目标行为，不是片中原文回放？ |
| 镜头映射 | 每个 Scene 是否只服务一个结论/目标？ |
| 母版一致 | 同一母版结构是否稳定，是否连续 3 镜以上同构？ |
| 声画同步 | 视觉锚点是否同步/略早于旁白，而不是整段先演完？ |
| 字幕/屏显 | 字幕单行；屏显不复述、不泄题？ |
| 成片指标 | 首帧非空、无长黑帧、-16±1 LUFS、字幕在安全区 |

Gate G5.5：E2E 错位清单 P0=0；否则回对应阶段改，不带病进渲染。

## 参数与阈值

| 项 | 推荐 |
|---|---|
| 分镜评审 | 1 个版式/连续性 Agent + Lead 裁决 |
| 成片评审 | 自动指标 + 1 个 QC Agent |
| E2E 评审 | 1 个独立 Agent；脚本+分镜后、成片后各 1 次 |
| 抽帧 | 每 2s 1 帧；首尾各 1 帧 |
| 响度 | -16 LUFS ±1；true peak ≤ -1.0 dBTP |
| 字幕 | 单行 ≤16 字；不重叠；不出安全区 |
| P0 | 必须清零 |
| Agent 结论 | 必须带帧号/时间码/引文，否则降级 |

## 常见反例

| 反例 | 问题 | 改法 |
|---|---|---|
| 只给脚本让 Agent 评成片 | 没有帧/声音证据 | 先抽帧/转录/跑指标 |
| Agent 说「整体不错」 | 不可执行 | 要求时间码 + P0/P1 + 改法 |
| 每个阶段都派 4 个 Agent | 成本高、重复 | 按阶段选角色；E2E 单独 1 人 |
| 分镜只看图不看目标 | 画面好看但没服务结论 | 分镜表加目标列 |
| 成片只看指标不看内容 | 技术过关但内容错 | 指标 + 抽帧 + 转录三件套 |
| 把 Agent 评审当试播 | 没有学生数据 | 只称「QC 通过」，试播后再说验证 |

## 验证方式

- 分镜表每镜有目标/来源/焦点；P0=0。
- 成片：首帧非空、无长黑帧、响度达标、字幕单行、声画锚点对得上。
- E2E：目标-证据-分镜三处映射无缺口；错位 P0=0。
- 有条件：5–10 人前测/后测，后测每目标 ≥4/5。
