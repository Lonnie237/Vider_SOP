# 钩子与留存 · 用前 3 秒把「刷到」变成「看完」

> 本文给「开头怎么写、怎么剪、怎么验证」的可执行规则。留存类阈值来自行业实践与账号基线，不来自平台公开文档，已在「依据」列标注为 [推断]；平台后台能提供对应指标，但算法权重未公开。

## 一句话定位

钩子（hook）是视频开头阻止观众划走的信息设计，留存（retention）是它是否有效的证据。用在 S0 选题定角度、S1 写开头、S4 粗剪自检；判断标准是发布后 3 秒留存与平均播放时长是否高于账号近 10 条的中位数。

## 适用场景

- 适用：9:16 短视频（口播知识 / 混剪卡点 / 直播切片）、长视频前 15 秒、信息流投放素材。
- 不适用：强需求长教程（如软件操作步骤）开头只做「结果预览」即可，不必强行制造冲突；系列内容第 N 集可直接承接上集，不必重复钩子。

## 原理与判断标准

- 为什么有效：观众在信息流里用 1–3 秒完成「与我有关吗」的筛选；先给结论 / 利益点，再解释，能减少划走 [推断]。平台把完播率、平均播放时长作为内容诊断指标，但各平台未公布具体权重 [推断]。
- 好钩子的四要素：
  1. 结果或结论先行（不铺垫）；
  2. 具体对象或数字（「90% 的人」「这一步」）；
  3. 冲突、反常识或损失（「别急着导出」）；
  4. 画面同时有信息（人脸 / 大字 / 动作），不是只有声音。
- 什么算好：3 秒留存 ≥ 70%，平均播放时长 ≥ 成片时长的 50%（15–60s 短视频），完播率 ≥ 30%；同时高于账号近 10 条中位数 [推断]。
- 什么算坏：开头 1 秒以上 logo / 片头动画；第一句是「大家好」；慢推空镜；钩子承诺与正文不符。

## 可操作步骤

1. 写 5 版钩子，每版 ≤ 2 句、≤ 20 字：结论前置 / 反常识 / 身份点名 / 损失厌恶 / 悬念。产出：钩子候选表（可写在 [分镜表](../../templates/分镜表.md) 第一行）。
2. 选 1 版做 3 秒样片：首帧起就有信息，无片头、无 logo，字幕与口播同步。产出：3 秒样片。
3. 检查开头 5 秒切点：至少 2 个信息点或镜头切换，避免死画面。产出：切点时间码。
4. 发布后 24 小时看后台 3 秒留存与平均播放时长；低于账号基线就只重剪开头，不动正文。
5. A/B 验证：同正文换两条钩子，间隔 ≥ 48 小时发布，或在不同账号同步测试；不要同时换钩子、标题、封面，否则无法归因。

## 参数与阈值

| 参数 | 推荐值 | 依据 | 备注 |
|---|---|---|---|
| 钩子时长 | 1.5–5s，且 ≤ 成片 15% | [推断] | 超过 5s 观众已开始判断「值不值得」 |
| 首帧信息延迟 | ≤ 0.2s | [推断] | 首帧不能是黑场 / logo |
| 3 秒留存 | ≥ 70%（账号基线 ±10%） | [推断] | 以后台「3s 播放」或留存曲线为准 |
| 平均播放时长 | ≥ 成片 50% | [推断] | 15–60s 短视频 |
| 完播率 | ≥ 30%（15–60s） | [推断] | 长视频改看「平均播放占比」 |
| 开头字幕 | ≤ 14 字/行，首屏 ≤ 28 字 | 见 [字幕与信息密度](subtitle-density.md) | 与口播同步出现 |
| 开头响度 | 不低于 -20 LUFS（整体 -14 LUFS） | 见 [声音设计](sound-design.md) | 突变音效别超过 -6 dBFS |
| 片头 / logo | 0s；logo 放片尾 2s 或简介 | [推断] | 品牌信息不占用前 3 秒 |

## 常见反例

| 反例 | 为什么不行 | 怎么改 |
|---|---|---|
| 3 秒片头 logo 动画 | 观众在前 1–2 秒已经划走 | 删掉片头，logo 放片尾或简介 |
| 「大家好，今天我们来聊聊…」 | 前 2 秒零信息 | 直接给结论：「90% 的人这一刀剪错了」 |
| 慢镜空镜开场 | 无信息、无人物、无冲突 | 用结果画面、手部动作或大字标题开场 |
| 钩子夸大、正文不兑现 | 完播与互动双低，长期伤账号 | 钩子只放大正文已有的结论 |
| 只改声音钩子、不改画面 | 听觉成立但视觉留人失败 | 音画同改：大字 + 动作 + 短音效 |
| 用 5 秒铺垫背景 | 流失最大的区间被浪费 | 背景压到中段，用字幕或画中画补 |

## 验证方式

- 切点检查（[实测] 2026-11-03，ffmpeg 9.0.2）：`scdet` 能在硬切处输出分数与时间码；2s 红 / 2s 蓝、25fps 的测试片段在 `pts_time=2` 处得到 `score=15.625`（阈值 8）。用同样命令看开头 5 秒有几个切点：

```bash
ffmpeg -hide_banner -i output.mp4 -t 5 -vf "scdet=threshold=8,metadata=print" -f null - 2>&1 | grep -E "lavfi.scd.(score|time)" | head -20
```

- 首帧检查：`ffmpeg -hide_banner -y -ss 0 -i output.mp4 -frames:v 1 first_frame.png`，确认有人脸 / 大字 / 动作。
- 数据检查：发布 24h 后把「3 秒留存、平均播放时长」与账号近 10 条中位数对比；连续 3 条低于中位数 20% 视为钩子失败。
- 失败信号：3 秒留存 < 50% 且平均播放 < 30%；评论区出现「所以呢」「说重点」；完播高但互动低，通常是钩子与内容人群不匹配。
