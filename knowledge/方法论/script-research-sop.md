# 视频脚本调研 SOP · 从主题到可拍脚本

## 一句话定位

**先定「观众看完能做什么」，再找「哪些事实支撑它」，最后才写「怎么说」；每一句抽象话都必须有来源、例子或证据。** 这套 SOP 用来避免「假大空」：不是文笔问题，是调研与教学设计缺环。

## 适用场景

- 科普、教育、产品讲解、知识类视频（45s–15min）。
- 需要「内容站得住」而不是「画面好看就行」的项目。
- 尤其适合教材/课程/产品等有权威源的题材。
- 不适用：纯娱乐、纯剧情、纯情绪短片。

## 原理与判断标准

### 1. 理论支撑（不是玄学）

| 理论 | 核心 | 对脚本的约束 |
|---|---|---|
| 逆向设计 Backward Design（Wiggins & McTighe） | 先定目标 → 再定证据 → 最后设计活动 | 先写「看完能做什么」和「怎么验证」，再写旁白 |
| ABCD 目标 / Bloom 分类 | 目标要含 Audience、Behavior、Condition、Degree | 目标必须可观察、可测量，不写「了解/感受」 |
| Mayer 多媒体学习原则 | 一致性、信号、冗余、空间/时间邻近、分段、预训练、通道、个性化 | 一屏一个信息；字幕别和旁白逐字重复；先讲术语再展开 |
| 认知负荷理论（Sweller） | 内在/外在/相关负荷；工作记忆有限 | 拆段、给例子、避免分屏找答案、避免装饰干扰 |
| 5E 教学模型 | Engage → Explore → Explain → Elaborate → Evaluate | 先制造疑问/经验，再解释，再应用，最后评估 |
| Merrill 首要教学原理 | 问题中心、激活旧知、示范、应用、整合 | 每个概念都要有「例子 + 练习 + 迁移」 |
| 概念转变理论（Posner 等） | 让旧概念「不满足」，新概念「可理解、合理、有效」 | 先暴露误区，再给反例，再给正确概念 |
| 提取练习（Roediger & Karpicke） | 测试比重读更能长期保持 | 片尾/片中要有 1–3 个回忆问题 |
| 课标/教材/权威文档 | 学科口径与边界 | 定义、顺序、术语以权威源为准 |

### 2. 什么叫「好脚本」

不是「文采好」，而是同时满足：

1. **准确**：每个事实有来源；推断有标记；不把「可能」写成「一定」。
2. **聚焦**：一个核心问题，2–4 个学习目标；不贪多。
3. **匹配受众**：先备知识、词汇、例子都在观众最近发展区内。
4. **具体**：抽象概念至少配 1 个正例 + 1 个反例/边界例。
5. **连贯**：因果链清楚；每段回答上一段留下的问题。
6. **认知可承受**：一镜一个结论；分段；不让人同时在画面里找答案。
7. **可视化**：每一拍都能想出画面；不能只靠旁白。
8. **可验证**：有 3–5 个问题/任务能证明观众学会了。
9. **可记忆**：有钩子、类比、收束、回顾；不是信息堆。
10. **可制作**：时长、素材、版权、渲染成本可控。

> 10 条按 1–5 分打分；平均 ≥4，且不能有 1–2 分项；事实项必须 5 分（SME 通过）。

## 可操作步骤

### Phase 0 · Brief（0.5h）

填清楚：

- 受众是谁？先备知识是什么？
- 平台/画幅/时长？
- 看完能做什么（1–3 条）？
- 不做什么（边界）？
- 成功标准（完播/测验/评论）？

产出：Brief 卡；Gate G0：目标可观察、边界清楚。

### Phase 1 · 来源与事实台账（2–4h）

来源优先级：

1. **Tier 1**：课标、教材、官方文档、同行评议论文、标准/规范。
2. **Tier 2**：权威机构科普、大学课程、专业百科。
3. **Tier 3**：博客/视频/自媒体——只做线索，不做依据。

每条 claim 记录：结论 / 来源 / 日期 / 置信度（事实/推断/待确认）/ 用在哪一段。

产出：事实台账；Gate G1：没有无来源事实；没有「据说/大家都知道」。

### Phase 2 · 学习者与误区（1–2h）

- 先备知识：观众已经会什么？不会什么？
- 3–5 个常见误区：错误说法 → 为什么错 → 正确说法 → 用什么例子/反例纠正。
- 词汇表：哪些术语必须解释，哪些可以默认。

产出：误区表；Gate G2：每个误区在脚本中有对应处理。

### Phase 3 · 概念/任务分析（1h）

- 画概念图：先备 → 核心概念 → 下一课；标出依赖关系。
- 定边界：这一条视频只讲什么，不讲什么。
- 准备正例、反例、边界例；能不用术语就不用。

产出：概念图；Gate G3：没有孤立概念，没有超纲依赖。

### Phase 4 · 目标与证据（1h）

- 写 2–4 条 ABCD 目标。
- 每条目标配 1–2 个证据：口头提问、选择题、应用题、判断题。
- 先写测验，再写旁白（逆向设计）。

产出：目标-证据表；Gate G4：每个 Scene 都能映射到目标；每个目标都有证据。

### Phase 5 · 脚本与分镜（2–4h）

结构可选：

- 教学型：Hook → 旧知激活 → 冲突/误区 → 概念 → 正例 → 反例 → 应用 → 回顾。
- 5E：Engage → Explore → Explain → Elaborate → Evaluate。
- 问题型：问题 → 尝试失败 → 新工具 → 解决 → 迁移。

脚本表至少含：

| 字段 | 要求 |
|---|---|
| 时间 | 精确到秒 |
| 旁白 | 口播稿，一句一个意思 |
| 屏显 | 关键词/数字，不复述旁白 |
| 画面/版式 | 用 [版式库](layout-patterns.md) 选型 |
| 揭示 | 先给结构/按锚点；字幕静态 |
| 目标 | 对应哪条学习目标 |
| 来源 | 对应事实台账条目 |

写完后做「三读」：

- **朗读**：拗口、过长、歧义；
- **删读**：删掉不影响理解的句子（删不掉才留）；
- **追问**：每句问「来源？例子？反例？」答不出就补或删。

### Phase 6 · 评审（1–2h）

- 默认：**Agent 评审团**（学科/学习科学/新手三个独立 Agent + Lead 裁决），见 [Agent 评审团](agent-review-panel.md)。
- 若有条件：再加真实学科教师（SME）抽检；没有也不阻塞，但不得称「已验证」。
- 教学评审：目标-证据-活动是否对齐；认知负荷是否过高。
- 制作评审：画面是否可实现；版权/素材是否可用。
- 事实复核：来源日期、版本、链接可访问。

Gate G5：P0 清零 + Lead 裁决记录；改稿后必须二轮 Agent 评审；未过不进 TTS/渲染。

### Phase 7 · 试播与迭代（1–2 周）

- 5–10 人试看：前测/后测 3–5 题；观察卡点；收集「哪句没听懂」。
- 指标：理解率、完播、回看、评论问题类型。
- 只改被数据/反馈指出的段落；不要凭感觉重写全片。

Gate G6：后测达标（例如 80% 正确）再发布。

## 参数与阈值

| 项 | 推荐 |
|---|---|
| 学习目标 | 2–4 条 |
| 核心问题 | 1 个 |
| 误区 | 3–5 个 |
| 每条目标证据 | 1–2 个 |
| 一镜结论 | 1 个 |
| 每分钟新术语 | ≤2 个 [推断] |
| 抽象句配例子 | 1:1 |
| 事实台账覆盖 | 100% claim |
| SME 事实通过 | 100% |
| 试播样本 | 5–10 人 |
| 后测达标 | ≥80% |

## 常见反例

| 反例 | 问题 | 改法 |
|---|---|---|
| 先写漂亮旁白再找资料 | 事实给文笔让路 | 先台账后脚本 |
| 目标写「了解/感受」 | 无法验证 | 改 ABCD 可观察行为 |
| 一镜塞 3 个结论 | 认知过载 | 拆镜/删 |
| 只有定义没有例子 | 抽象、假大空 | 加正例/反例/边界例 |
| 用「众所周知」 | 无来源 | 找 Tier 1/2 或删 |
| 只写「为什么重要」 | 没有机制 | 补因果链/证据 |
| 不做试播 | 不知道观众卡在哪 | 5 人前测后测 |
| 把动画当内容 | 画面热闹但没学到 | 先目标-证据再视觉 |

## 验证方式

- 事实台账逐条核对；无来源项为 0。
- 目标-证据表：每条目标有证据；每个 Scene 有目标。
- 10 项脚本评分 ≥4 且无 1–2 分。
- 朗读/删读/追问三读通过。
- SME 100% 通过。
- 5–10 人试播，后测 ≥80%。
