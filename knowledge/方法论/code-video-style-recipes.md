# 纯代码视频风格库 · 11 种风格配方

## 一句话定位

把「一段 3 秒的风格展示」拆成可复用的美术配方：**观感 + 调色板 + 构图 + 6 拍动效 + 音色 + 实现要点**。适用于纯代码卡点展示片、数据动画的段间包装、以及需要多种视觉语言的系列片。

## 适用场景

- 30–90s 多风格卡点展示片（产品/能力/年度回顾）。
- 数据动画、知识视频的段落包装：同一主题下切换视觉语言。
- 需要「可复现、无生成模型」的视觉资产生产。
- 不适用：真人实拍、写实叙事、需要复杂三维资产的商业片。

## 原理与判断标准

- **每段 3s / 6 拍**，120 BPM 下 1 拍 = 0.5s；结构固定：

| 拍 | 时间 | 任务 |
|---|---|---|
| 0 | 0.0s | 硬切 + 卡点冲击，主视觉第一帧就成立 |
| 1 | 0.5s | 主视觉入场（滑入/生长/翻页） |
| 2 | 1.0s | 标题/主文案到位 |
| 3 | 1.5s | 叙事推进（第二元素 / 数据 / 运镜） |
| 4 | 2.0s | 细节 / 标签弹出 |
| 5 | 2.5s | 收束到最终构图，留最后一拍给下一段硬切 |

- **每段只允许 1 个主视觉 + 1 句主文案 + 2–3 个辅助元素**；3 秒内信息过载必花。
- 段首第一帧必须「满」：主视觉 + 标题 + 底色已成立，不从黑屏开始。
- 段尾 0.3s 做「收力」（元素停稳/光晕衰减），硬切才有劲。

## 可操作步骤

1. **锁定整体骨架**：黑底/纸底 + 一个品牌强调色；段间用大字卡切换（见 [纯代码视频管线](../工作流/code-video-pipeline.md)）。
2. **选 2–4 种风格**：不要 11 种全上；按「内容需要」选（科普→01、数据→07、品牌→03、文化→06）。
3. **为每种风格准备 1 张参考静帧**：先固定构图，再写动效。
4. **按 6 拍写时间函数**：入场/主文案/推进/细节/收力，全部是 `t` 的函数。
5. **配色回主题**：风格段保留自身色板，胶囊/HUD/水印用主题 chrome（见 [主题库](code-video-themes.md)）。
6. **音色跟随节拍**：每拍一个声音事件；不要整段铺满。

## 参数与阈值

| 参数 | 推荐值 | 依据 |
|---|---|---|
| 每段时长 | 3s（6 拍） | 卡点展示片惯例；长于此观众注意力下降 |
| 段间大字卡 | 1s（2 拍） | 给切换一个呼吸点 |
| 单段镜头运动 | ≤2 次（推/环/切） | 3 秒内运镜过多会晕 |
| 每段颜色 | 主色 + 强调 + 黑/白，≤3 色 | 超过 3 色辨识度下降 |
| 文字层级 | 主文案 1 句 + 辅助 2–3 个 | 信息过载必花 |
| 故障/闪白时长 | 1–2 帧（0.03–0.07s） | 过长会廉价 |

## 常见反例

| 反例 | 为什么不行 | 怎么改 |
|---|---|---|
| 11 种风格全用在一支片 | 没有统一气质，像模板拼盘 | 选 2–4 种，片头/卡/结尾回到主题骨架 |
| 每段都从黑屏入场 | 卡点冲击消失 | 第一帧就满构图，硬切进入 |
| 3 秒塞 5 个信息点 | 观众记不住 | 1 主视觉 + 1 主文案 + 辅助元素 |
| 风格段沿用高饱和霓虹，主题是浅色 | 整片气质被打穿 | 用主题 accents 替换 1–2 个颜色，或叠 4–8% 主题色 |
| 每帧重算 fbm/模糊 | 渲染慢、掉帧 | 预渲染纹理/离屏 canvas，只更新透明度 |
| 音效每帧触发 | 声音糊成一片 | 按拍触发，一事件一声音 |

## 验证方式

- 抽帧：每段 0.2/0.8/1.4/2.0/2.6s 各一张，检查构图与字体。
- 播放：连续看 3 段，确认风格切换不跳戏、卡点对齐。
- 帧数：每段 `round(duration×30)`；全片帧数与剪辑表一致。
- 对比度：主题浅底时检查 HUD 是否换成深色实体。
