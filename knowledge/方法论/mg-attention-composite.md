# MG 注意力复合 · 用动态图形解决“内容单调”

## 一句话定位

**MG 不是加粒子/加漂浮，而是按注意力曲线安排“视觉事件”**：宏观章节卡、中观镜头切分、微观数字/形状变化；每个动作都要服务当前结论。目标是让观众每 4–8 秒有一个新的“看这里”的理由，而不是让画面一直动。

## 适用场景

- 知识/科普/产品讲解，画面以信息图、卡片、数轴、UI 为主。
- 现有视频被反馈“单调、抓不住注意力”。
- 已有脚本/分镜/版式卡，需要在不改内容的前提下加动效层。
- 不适用：纯剧情、角色表演、实拍采访（动效逻辑不同）。

## 原理与判断标准

### 1. 单调的真正原因

不是“动效太少”，通常是：

- 一个版式撑 30–50 秒（本仓数学全片 S2 约 50 秒同两栏）；
- 数字/文字静态，只有旁白在变；
- 场景之间只有硬切，没有“章节感”；
- 动效是背景漂浮，和当前结论无关；
- 每镜信息密度低，观众没有“下一拍会变什么”的预期。

### 2. 注意力复合的三层

| 层 | 作用 | 频率 | 例子 |
|---|---|---|---|
| 宏观 | 章节/段落重置 | 每 Scene 1 次 | 章节卡、进度条、转场 |
| 中观 | 镜头/构图变化 | 每 5–8 秒 | 硬切近景、左右聚焦、缩放 |
| 微观 | 当前焦点变化 | 每 2–4 秒 | 数字滚动、卡片翻面、线生长、点落下 |

### 3. 规则

1. **一个镜头一个焦点**；动效只强化当前结论。
2. **每 4–8 秒必须有一次可感知的视觉变化**（构图/焦点/数字/形状）。
3. **每 20–30 秒一次大重置**（章节卡/场景切换）。
4. 一镜最多 1 个主运动 + 1 个辅助运动；不要全屏同时动。
5. 连续镜头不超过 8 秒；超过就切近景/换构图。
6. 动效不遮挡字幕、不改变安全区、不缩字号。
7. 不用无意义漂浮、随机粒子、持续抖动；这些是“噪音”，不是注意力。
8. 需要真实数据/学习效果验证；动效只解决“看下去”，不保证“学会”。

## 可操作步骤

1. **审计**：每 2 秒抽帧，标出连续同构图时长；找出 >8 秒无变化的段落。
2. **切镜头**：按 5–8 秒把长段落切成近景/中景/全景；每切一次只换构图，不换内容。
3. **加章节卡**：每 Scene 开始 0.6–0.8 秒全屏“编号 + 标题”，形成段落感。
4. **加微动效**：数字滚动、卡片翻转、线生长、点落下、当前项放大；每个都绑旁白锚点。
5. **加转场**：只在 Scene 切换用 0.2–0.3 秒擦除/推拉；不要每个 cut 都加。
6. **复核**：抽帧看是否“每 4–8 秒有新东西”；遮住旁白看是否能看懂。
7. **试播**：看完播/停留/回看；动效不是越多越好。

## 参数与阈值

| 项 | 推荐 |
|---|---|
| 同构图最长 | ≤8s |
| 视觉变化间隔 | 4–8s |
| 大重置 | 20–30s |
| 章节卡 | 0.6–0.8s |
| 主运动时长 | 0.3–0.6s |
| 同时运动元素 | ≤2 |
| 缩放上限 | 1.06（1080p 安全区） |
| 转场 | 0.2–0.3s |
| 字幕 | 不遮挡、不缩放 |

## 常见反例

| 反例 | 问题 | 改法 |
|---|---|---|
| 全屏粒子/漂浮 | 看起来动，实际是噪音 | 删；用焦点动效 |
| 每个字都弹 | 认知过载 | 一段只强调 1 个词 |
| 每 2 秒切镜头 | 晕、碎 | 5–8 秒一切 |
| 动效与结论无关 | 观众看热闹没学到 | 动效服务当前结论 |
| 只加背景音乐/转场 | 不解决信息单调 | 改构图/焦点/数字 |
| 用 MG 掩盖内容空 | 更空 | 先补内容，再加动效 |

## 验证方式

- 2 秒抽帧：同构图是否 ≤8s？每 4–8s 是否有变化？
- 遮住旁白：静帧能否说出当前结论？
- 字幕/安全区是否被遮挡？
- 5–10 人试播：完播、停留、回看；不是只看“炫不炫”。
