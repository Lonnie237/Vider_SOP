# 叙事结构 · 用一条命题组织信息推进

> 结构不是「起承转合」四个字，而是观众每一段都能回答「现在在讲什么、为什么继续看」。本文给可填写的结构模板、字数换算与验证方法。

## 一句话定位

把散点信息组织成有推进力的序列，让观众看到结尾、并能用一句话复述。用在 S1 脚本与分镜；判断标准是「单条命题 + 每 15–20 秒有信息增量 + 结尾有落点」。

## 适用场景

- 适用：口播知识、教程长视频、访谈播客、产品宣传片、数据动画。
- 不适用：纯卡点混剪（用 [节奏与卡点](pacing-beat.md) 组织，不必套叙事）；流水账式 Vlog 可用「事件流 + 章节」代替强冲突结构。

## 原理与判断标准

- 为什么有效：观众持续观看依赖「预期—缺口—兑现」的循环；先立问题或结论，制造需要被填的缺口，再用证据逐段兑现 [推断]。ABT（And, But, Therefore：然后、但是、所以）是短视频与广告常用的最小叙事骨架 [推断]。
- 什么算好：
  - 一条视频只有 1 个核心命题（≤ 25 字能说清），最多 3 个支撑点；
  - 每 15–20 秒有 1 个新信息点或转折；
  - 背景介绍占比 ≤ 15% 时长；
  - 结尾给出落点（结论 / 行动 / 下一步），不引入新命题。
- 什么算坏：平铺三件事没有转折；前 30 秒讲背景；每段都在重复同一结论；结尾「就这样吧」；信息量与标题承诺不匹配。

## 可操作步骤

1. 写一句话命题：观众看完应记住什么，≤ 25 字。产出：命题句。
2. 选骨架：
   - 短视频（15–90s）：ABT 或「问题 → 方案 → 证据」；
   - 长视频（5–30min）：「总 → 分章 → 总」+ 章节标题；
   - 访谈 / 播客：主题章 + 金句前置；
   - 宣传片：痛点 → 产品 → 证据 → 行动。
3. 写信息卡：每块 = 钩子句（≤ 20 字）+ 证据（画面 / 数据 / 演示）+ 转折句；一段只讲一件事。
4. 落分镜：把信息卡填进 [分镜表](../../templates/分镜表.md)，标注画面、口播、时长、字幕。
5. 删减：删掉不能推进命题的段落；把最反常识的一句提到开头或结尾；把最弱的一段压成字幕 / 画中画。
6. 字数换算：中文口播约 240–300 字/分钟 [推断]，按成片时长配字数，避免写超后硬删。

## 参数与阈值

| 参数 | 推荐值 | 依据 | 备注 |
|---|---|---|---|
| 核心命题数 | 1 条 / 视频 | [推断] | 多命题会稀释完播 |
| 支撑点数 | 2–3 个 | [推断] | 超过 3 个改系列 |
| 信息增量间隔 | 每 15–20s 1 个 | [推断] | 长视频可放宽到 30s |
| 背景介绍占比 | ≤ 15% 时长 | [推断] | 短视频 ≤ 10% |
| 短视频结构 | 钩子 3s / 主体 2–3 转折 / 落点 3–5s | [推断] | 适用 15–90s |
| 长视频章节 | 每 3–5min 一章，每章 1 命题 | [推断] | 章节标题进进度条 |
| 转折数 | 短视频 2–3 次；长视频每章 1 次 | [推断] | 转折 = 「但是 / 然而 / 结果」 |
| 结尾 | 落点 + CTA，≤ 10s | [推断] | 不引入新信息 |
| 口播语速 | 240–300 字/分钟 | [推断] | 60s ≈ 240–300 字 |
| 复述测试 | 陌生人能复述 1 句 | [推断] | 复述不出 = 结构失败 |

## 常见反例

| 反例 | 为什么不行 | 怎么改 |
|---|---|---|
| 开头先讲 30 秒背景 | 流失发生在最贵的区间 | 结论前置，背景拆成字幕或中段补充 |
| 三段并列无转折 | 观众不知道「然后呢」 | 每段之间加「但是 / 结果」句 |
| 一条视频塞 5 个观点 | 没有重点，完播与收藏都低 | 拆成系列，每条只留 1 命题 |
| 结尾只说「就这样」 | 没有落点，互动与关注转化低 | 结尾给行动 / 下一步 / 提问 |
| 长视频没有章节 | 观众无法跳看，平均播放时长低 | 每 3–5min 设章节 + 进度条标题 |
| 文案按书面语写 | 口播拗口、语速失控 | 按 240–300 字/分钟写口语短句 |

## 验证方式

- 结构自检：每个信息块是否同时有「钩子句 + 证据 + 转折句」；缺一项就补。
- 复述测试：找 1 个没看过内容的人看一遍，请他复述；复述不出核心命题就重写结构。
- 数据验证：看后台留存曲线，单段掉点 > 15% 的位置对应哪张信息卡，优先重剪该段。
- 字数验证：`python3 -c "t=open('script.txt').read(); print(len(t), 'chars')"` 与目标时长换算对比（60s ≈ 240–300 字）。
- 失败信号：评论区问「重点是什么」；完播率低但前 3 秒留存正常（说明钩子成立、结构失败）。
