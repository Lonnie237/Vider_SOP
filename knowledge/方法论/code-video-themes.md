# 纯代码视频主题库 · 8 套配色与材质系统

## 一句话定位

主题不是「换三个颜色」，而是**角色色板 + 材质 + HUD 规格 + 点缀色**四层一起换；本条目给出 8 套可直接套用的主题与换色规则，适用于纯代码展示片、数据动画与品牌视频。

## 适用场景

- 同一内容需要不同品牌气质（暗场/纸感/工业/东方/剧场）。
- 多集系列片需要统一主题，同时允许风格段保留辨识度。
- 不适用：需要严格品牌 VI 的商用项目（应以品牌规范为准，再映射到本主题 token）。

## 原理与判断标准

四层结构缺一不可：

| 层 | 解决什么 | 字段 |
|---|---|---|
| 角色色板 | 底色/主字/强调/纸面/暗卡各有定义，浅色主题尤其不能混用 | colors（14 个 token） |
| 材质 | 颗粒/纸面/玻璃/烫金/网格/水墨/聚光，决定质感 | material |
| HUD | 胶囊/倒计时/水印：暗底用浅色半透明，浅底必须换深色实体 | hud |
| 点缀色 | 风格段主色的替换色，避免风格段把整片气质带跑 | accents（4 个） |

只换主色的典型翻车：浅色主题沿用半透明黑胶囊（像脏补丁）；深色主题暗卡在白纸上消失；风格段高饱和霓虹打穿莫兰迪。

## 可操作步骤

1. **先选主题再选风格**：主题决定骨架（背景/字/强调/HUD），风格段是骨架里的内容块。
2. 按内容气质选 1 套：发布/产品→01/04/06；知识/访谈→02；东方/文化→07；数据/工程→05/06；时尚/预告→08。
3. 应用四层 token：背景、主字、强调、纸面、暗卡、HUD 胶囊、倒计时、水印、4 个 accents。
4. 风格段默认保留原色板，只换左上胶囊编号色、右下倒计时、右上水印。
5. 浅色主题遇到深底风格段：用 accents 替换 1–2 个颜色，或叠 4–8% 主题底色（成本低于重画）。
6. 片头、大字卡、结尾必须回到主题骨架色。

## 参数与阈值

| 参数 | 推荐值 | 依据 |
|---|---|---|
| 一套主题颜色 token | 14 个角色色 | 区分 ground/ink/accent/paper/dark |
| 风格段换色 | 每段 ≤2 个 | 换多丢失配方辨识度 |
| 浅色主题叠色 | 4–8% | 再高会脏 |
| HUD 透明度 | 暗底 0.72，浅底用 0.88–0.9 的深墨 | 保证可读性 |
| 对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1 | WCAG 基线 |
| 主题数量 | 8 套（4 深 4 浅） | 覆盖常见品牌气质 |

## 常见反例

| 反例 | 为什么不行 | 怎么改 |
|---|---|---|
| 只换背景色，不换 HUD | 浅底上半透明黑胶囊像脏块 | 用 `chrome(theme)` 换 HUD 规格 |
| 深色主题配纸面暗卡 | 暗卡在白纸上消失 | 暗卡跟随主题（浅色主题用深墨卡） |
| 风格段高饱和霓虹不压 | 打穿莫兰迪/青瓷气质 | 用 accents 替换，或叠主题色 |
| 11 段各用一套主题 | 整片无统一骨架 | 一套主题 + 风格段局部色 |
| 金色做成大面积渐变 | 像廉价年会 | 只做标题斜向 sheen，不铺底 |

## 验证方式

- 对比度审计：正文/大字分别过 4.5:1 / 3:1。
- 抽帧：浅色主题下检查 HUD、暗卡、脚注是否可读。
- 一致性：片头/卡/结尾回到骨架色；风格段最多 2 个替换色。
- 换主题重渲：不改剪辑表与文案，只换主题 id。
