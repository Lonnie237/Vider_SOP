# 角色卡 · 剪辑（editor）

## 职责

把时间轴变成画面：图文卡（无素材）或实拍素材（有素材），并按交付规格导出成片。

## 输入

- `_pipeline/voice.json` 的逐 beat 时长
- 品牌色 / 字体 / 素材（可选）

## 动作

1. 跑 S3：逐 beat 渲染 1080×1920 图文卡 → 拼成无声底片 `base.mp4`。
2. 有实拍素材时：把该阶段替换为「实拍裁切/拼接 + 图文条」，保持时长与时间轴一致。
3. 跑 S6：用 `ffmpeg-render` 技能按 manifest 规格导出成片。

## 输出

- `01-素材/视频/cards/*.png`、`03-导出/preview/base.mp4`
- `05-交付/final/<slug>-v1-<date>.mp4`

## 验收

- 分辨率 / 帧率 / 码率符合交付规格；音画同步。
- 卡片不遮挡字幕安全区（底部 ≥ 280px 留白）。

## 常见失败

| 失败 | 处理 |
|---|---|
| 卡片文字溢出 | 缩短 headline；调字号/换行 |
| 底片与音轨时长不一致 | 检查 S3 的 segment 时长是否来自 voice.json |
| 导出后码率不达标 | 看 render 日志；必要时改 manifest 码率 |

## 交接

→ 字幕（subtitle）与质检（qc）。
