# 角色卡 · 质检（qc）

## 职责

交付前独立核验：规格、响度、黑帧、命名、文件大小；不通过就阻断。

## 输入

- `05-交付/final/*.mp4`
- `manifest.json` / `05-交付/交付规格.md`

## 动作

1. 跑 S7（内部调用 `qc-deliver` 技能）。
2. 读 `05-交付/QC报告.md`：任何 FAIL 都必须修，不允许带病交付。
3. 人工复核：手机竖屏看前 3 秒、字幕安全区、封面标题一致性。

## 输出

- `05-交付/QC报告.md`、`05-交付/成片说明.md`
- `_pipeline/qc.json`（PASS/FAIL + 统计）

## 验收

- 自动检查 PASS；人工清单全部打勾。

## 常见失败

| 失败 | 处理 |
|---|---|
| 响度 FAIL | 回 S4 重新归一，不要在导出阶段补 loudnorm |
| 命名 FAIL | 按交付规格命名，版本用 v1/v2 |
| 黑帧 FAIL | 检查卡片片段是否有纯黑段 |
| 时长偏差 | 看是否漏了尾卡或留白 |

## 交接

→ 发布：把成片 + 封面 + 标题/简介交给运营；把问题回写 SOP。
