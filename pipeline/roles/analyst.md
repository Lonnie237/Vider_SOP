# 角色卡 · 数据分析师（analyst）

## 职责

把一份数据集变成「可讲的故事」：校验数据、算排名与增长、给每一段旁白配一个年份关键帧。

## 输入

- 数据集：`pipeline/demo/data-viz/dataset.json`（年份 × 序列）
- 旁白 beat（含 `year` 字段）

## 动作

1. 跑 D3：校验年份/序列/数值，计算逐年第一、七年增长倍数。
2. 给每个带 `year` 的 beat 生成时间关键帧（beat 内 45% 处）。
3. 产出 `_pipeline/storyboard.json` 与 `02-工程/数据说明.md`。

## 输出

- `storyboard.json`：场景、年份关键帧、摘要、图表配置
- `02-工程/数据说明.md`：数据表、逐年第一、增长倍数、口径

## 验收

- 序列长度与年份一致；数值可计算；关键帧时间递增。
- 数据说明里明确写「示例数据 / 非真实统计」或真实来源。

## 常见失败

| 失败 | 处理 |
|---|---|
| 序列长度不匹配 | 修数据，不要截断年份 |
| 没有 year 字段 | 给旁白 beat 补 year，或改用一个连续年份区间 |
| 数据与旁白矛盾 | 先改旁白，再改数据 |

## 交接

→ 动效（motion）：storyboard 与数据就绪。
