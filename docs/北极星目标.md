# 北极星目标与自主推进规则

- 建立日期：2026-11-13
- 状态：**长期有效**
- 适用：本仓库所有后续推进（Lead 自主执行，不需逐次请示）

## 1. 北极星（唯一目标）

> 把“做视频”从个人手感，变成**可检索、可复用、可执行、可交给 Agent 跑**的工程资产。

## 2. 达成的判定（五条，缺一不可）

1. **一条命令**：给 brief + 素材，一条命令产出可发布成片，中途不用人改脚本；
2. **四类形态闭环**：口播、数据动画、教程长视频、产品/宣传片各至少 1 条端到端实测；
3. **真实素材验证**：真实素材/数据跑通并 QC PASS，不是模板 demo；
4. **Agent 真的在做**：阶段提示词交给 Agent 执行，失败能定位、重试、上报；
5. **数据回流**：发布数据（完播/打开/留存）回写复盘，修正 SOP 与钩子。

## 3. 阶段规划

| 阶段 | 内容 | 完成标志 |
|---|---|---|
| P4 真实闭环 | Agent 接管 2–3 阶段；真实素材端到端；四类形态各 1 条流水线 | 第 1–4 条达成 |
| P5 数据闭环 | 发布数据回流；复盘自动生成“下一版改什么”；SOP 按数据迭代 | 第 5 条达成 |

**P4 完成即可宣布目标达成；P5 是持续变好。**

## 4. 推进规则（自主执行）

- 按 P4 → P5 顺序推进，不等待逐次确认；
- 一次只做一件事：一个缺口 → 一个产物 → 一次验证 → 一次提交；
- 每完成一项，更新 [docs/北极星进度.md](北极星进度.md)；
- 遇到方向性选择（换形态、换技术栈、砍功能），先做小实验再决策，不反复请示。

## 5. 定时复盘（防偏离）

- **频率**：每个工作段结束 + 每完成一个 P4/P5 子项；
- **产出**：docs/北极星进度.md 的「复盘」节，四句话：
  1. 这个阶段做了什么；
  2. 离五条判定还差什么；
  3. 有没有偏离（做了不服务目标的事）；
  4. 下一步一件事。
- **偏离判定**：任何不属于五条判定的工作，记为「偏离」并停止或降级为支线。
