# 术语表

> 全仓统一用词。写作或评审时**第一次出现**按此表中文 + 英文；同一概念不要混用多个叫法。

## 流程与角色

| 术语 | 英文 | 解释 |
|---|---|---|
| SOP | standard operating procedure | 一类视频从选题到交付的标准流程，本仓 `sop/` 下按形态拆分 |
| 技能 / Skill | skill | 给 Agent 的可执行流程包：触发条件 + 步骤 + 失败处理 + 自检 |
| 粗剪 | rough cut | 只解决结构与信息完整，不修细节 |
| 精剪 | fine cut | 节奏、表演、转场、画面取舍 |
| 母版 | master | 最高质量交付版本，供后续转码 |
| 代理剪辑 | proxy editing | 用低码率副本剪辑，最终回套原素材 |
| 回套 / 套底 | conform | 代理时间线对回原始素材并输出 |
| 时间线 | timeline | NLE 中按时间排列的轨道集合 |
| 工程 | project | NLE 工程文件及其依赖（字体、LUT、素材） |
| 交付规格 | delivery spec | 分辨率/帧率/编码/码率/音频/字幕/封装的固定组合 |
| 质检 | QC | 交付前逐项核对规格与内容 |
| 返工 | rework | 不达标导致的重复制作 |

## 剪辑语言

| 术语 | 英文 | 解释 |
|---|---|---|
| 景别 | shot size | 远景/全景/中景/近景/特写 |
| 运镜 | camera movement | 推拉摇移跟升降 |
| 分镜 | storyboard / shot list | 镜头级制作清单 |
| B-roll | B-roll | 覆盖镜头、空镜、辅助画面 |
| 蒙太奇 | montage | 通过镜头组接产生新含义 |
| 卡点 | beat cut | 画面切换对齐音乐节拍 |
| BPM | beats per minute | 音乐每分钟节拍数，卡点基准 |
| 跳切 | jump cut | 同机位同景别直接切，制造紧凑感 |
| J-cut / L-cut | J-cut / L-cut | 声音先进/后出的错位剪辑 |
| 转场 | transition | 切、叠化、划像、遮罩转场等 |
| 变速 / 速度斜坡 | speed ramp | 变速曲线，用于强调或衔接 |
| 关键帧 | keyframe | 参数随时间变化的锚点 |
| 遮罩 / 蒙版 | mask | 局部显示/隐藏区域 |
| 跟踪 | tracking | 让元素跟随画面运动 |
| 花字 | kinetic caption | 强调性字幕/图形文字 |

## 画面与技术参数

| 术语 | 英文 | 解释 |
|---|---|---|
| 帧率 | frame rate | 每秒帧数；交付与素材一致优先 |
| 分辨率 | resolution | 像素尺寸；竖屏 1080×1920 写作 9:16 |
| 码率 | bitrate | 单位时间数据量；CBR 恒定 / VBR 可变 |
| CRF | constant rate factor | x264/x265 质量档，数值越小质量越高 |
| 封装 | container | .mp4 / .mov / .mkv，装视频/音频/字幕轨 |
| 编码 | codec | H.264 / H.265 / AV1 / ProRes |
| 像素格式 | pixel format | 交付常用 `yuv420p` 保证兼容 |
| 色彩空间 | color space | 交付常用 Rec.709 |
| LUT | lookup table | 调色查找表 |
| 一级校正 | primary correction | 曝光、白平衡、对比度统一 |
| 二级调色 | secondary grading | 局部/特定颜色调整 |
| 中间格式 | intermediate codec | ProRes / DNxHR，剪辑与归档用 |

## 声音

| 术语 | 英文 | 解释 |
|---|---|---|
| 响度 | loudness | 感知音量，单位 LUFS；短视频 -14、长视频 -16 |
| 真峰值 | true peak | 峰值上限，常用 -1.5 dBTP |
| 响度标准化 | loudness normalization | FFmpeg `loudnorm` 按 EBU R128 调整 |
| 降噪 | noise reduction | 去底噪/电流声 |
| 压缩 | compression | 缩小动态范围，让人声更稳 |
| 均衡 | EQ | 频段增益调整 |
| 混音 | mixing | 对白/音乐/音效比例与空间处理 |
| 音效 | SFX | 转场、强调、环境声等 |
| BGM | background music | 背景音乐 |

## 内容与增长

| 术语 | 英文 | 解释 |
|---|---|---|
| 钩子 | hook | 前 3 秒抓住注意力的设计 |
| 留存 | retention | 观众继续观看的比例 |
| 完播率 | completion rate | 看完比例 |
| 信息密度 | information density | 单位时间有效信息量 |
| CTA | call to action | 引导关注/评论/购买 |
| 三幕结构 | three-act structure | 建置-对抗-解决 |
| 起承转合 | four-part structure | 中文叙事的四段式 |
| 封面 / 标题 | thumbnail / title | 决定点击率（CTR） |
| CTR | click-through rate | 点击率 |
| 平台规格 | platform spec | 各平台分辨率/时长/码率/审核规则 |

## 工具与格式

| 术语 | 英文 | 解释 |
|---|---|---|
| NLE | non-linear editor | 非编软件：Premiere / DaVinci / FCP / 剪映 |
| FFmpeg | FFmpeg | 命令行音视频处理工具链 |
| OTIO | OpenTimelineIO | 开放时间线交换格式 |
| EDL / XML | edit decision list | 剪辑决策表 / 交换工程 |
| SRT / ASS | subtitle formats | 外挂字幕 / 带样式字幕 |
| ASR | automatic speech recognition | 语音转文字（转写） |
| 代理文件 | proxy file | 低码率剪辑副本 |
| 场景检测 | scene detection | 自动识别镜头切换点 |
| 黑帧检测 | black frame detection | 检出黑场/丢帧 |
| 硬件编码 | hardware encoding | videotoolbox / NVENC / QSV |
