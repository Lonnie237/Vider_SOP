| 组件 | 文件 | 说明 |

## 3. 门禁验证

- 失败即停：模拟 S5-subtitle 失败 → 后续保持 pending，retro「返工点」列出该阶段；
- 恢复：重新标记 done 后 retro 清零；
- 门禁文案：全部 done 才显示「可完成」，否则显示「未完成：<stage>」。

## 4. 与 P2 的关系

P2 的 orchestrator 只保证「阶段能跑」；P3 补上：

- 谁做（claim/owner）、做了几次（attempts）、为什么失败（note）；
- 完成度门禁（status）；
- 复盘（retro.md）可直接喂给下一轮规划。

## 5. 遗留

| 项 | 影响 | 下一步 |
|---|---|---|
| 没有真实子 Agent 分工 | 当前是「调度器 + 角色标签」，执行仍是脚本 | 接 Agent 时把阶段提示词交给角色卡执行 |
| 复盘只统计尝试次数 | 没有工时/返工原因分类 | 接真实运行后补 |
| 只有两条流水线接入 | 其余两条数据动画未跑新调度器 | 同命令补跑即可 |
| 发布数据未回流 | 无法修正钩子/时长 | 有数据后接「成片复盘 Agent」 |
