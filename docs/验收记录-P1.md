## 4. Lead 人工抽检

### 4.1 结构一致性

- 8 条 SOP 均为 13 个 `##` 必备节，frontmatter 的 `id` 与文件名一致。
- 交付参数统一：竖屏 1080×1920 / 30fps / H.264 High VBR 8–16Mbps / AAC 48k 192k / -14 LUFS；横屏 1920×1080 / 6–12Mbps / -16 LUFS。
- 全部 SOP 与技能**未使用** `subtitles` / `ass` / `drawtext` 滤镜命令（本机 FFmpeg 无 libass/freetype），字幕只走 NLE 烧录或 Pillow overlay。

### 4.2 可执行性冒烟测试

| 对象 | 命令 / 场景 | 结果 |
|---|---|---|
| `qc-deliver` | 对 1080×1920 / 4s 测试片核规格 | 13 PASS / 1 FAIL（响度 -21.8 LUFS 未达 -14），FAIL 判定正确 |
| `subtitle-pipeline` | `subtitle.py probe` | subtitles/ass/drawtext 不可用、overlay 可用，推荐 Pillow，与环境条目一致 |
| `video-project-init` | 生成 1080×1920 口播项目 | 15 个目录 + Brief/分镜/交付规格/QC/manifest，退出码 0 |
| `ffmpeg-render` | `--dry-run` 读取 manifest | 命令含 scale/pad/fps/6000k/loudnorm，退出码 0 |

### 4.3 事实抽检

- FFmpeg 9.0.2 构建无 libass/freetype：本机实测（`ffmpeg -filters` / `-buildconf`），已写入 [环境条目](../knowledge/环境/environment-local.md) 与 ffmpeg 坑位。
- moviepy 2.2.1、PyAV 19.0.2、Remotion 4.0.540 等版本信息均在条目「来源」附 URL + 访问日期 2026-11-03。
- 平台参数中抖音/B站/YouTube 部分受登录态限制，已标 `[待确认]`，未编造。

- **结构**：规范、模板、索引、校验闭环成立；新条目复制模板即可进入门禁。
- **内容**：S0–S11 主流程覆盖，8 类视频形态有可执行 SOP；知识条目全部达到「可用」。
