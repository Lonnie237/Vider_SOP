- 日期：2026-11-13
- 命令：python3 pipeline/publish_kit.py --run-dir <run> --platform 视频号 ...
- 产物：<run>/05-交付/publish/

## 文件

| 文件 | 用途 |
|---|---|
| product-promo-collector-v1-2026-11-13.mp4 | 横屏主片 |
| vertical.mp4 | 竖屏版 |
| cover.png | 封面 |
| 发布文案.md | 标题、正文、话题 |
| 数据回收.csv | 每天一行：播放/完播/资产页/WorkBuddy/首次任务 |
| retro-data.template.json | 真实数据回填模板（baseline 131） |

## 使用

1. 先发竖屏，再发横屏；
2. 发布后每天填数据回收.csv；
3. 7 天后把汇总填进 retro-data.template.json，改名为 retro-data.json 放到 <run>/_pipeline/；
4. 跑 board --retro 与 release_check。

## 限制

- 发布包已生成，但还没发布；
- 数据回收表是空的，不能拿示例数据当真实数据。
