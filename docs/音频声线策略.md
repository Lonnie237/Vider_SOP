# 音频声线策略（2026-11-18）

## 1. 决定

- **主用**：阿里云 TTS，用户指定的声线（voice id 待提供）。
- **备选 1**：阿里云 Tingting（同供应商，音色接近，但不是主用声线）。
- **备选 2**：macOS Tingting（仅无阿里云凭证/服务不可用时的最后兜底，默认只能用于草稿）。
- 若用户不提供阿里云：使用备选 1；备选 1 也不可用时，使用备选 2，并明确标注差距。

## 2. 关键区分：阿里云 Tingting 不等于 macOS Tingting

同名不代表同一音色：

| 项 | 阿里云 Tingting | macOS Tingting |
|---|---|---|
| 引擎 | 阿里云 TTS | Apple say |
| 音色 | 阿里云声线 | 系统声线 |
| 发音/停顿 | 云端韵律 | 系统韵律 |
| 采样率/后处理 | 可控 | 固定 |
| 公开成片 | 可 | 默认不可，需书面豁免 |

**不能把 macOS Tingting 标成“阿里云 Tingting”。**

## 3. 降级级别

| 级别 | 声线 | 用途 | 公开成片 |
|---|---|---|---|
| L0 | 阿里云主用 | 正式 | 允许 |
| L1 | 阿里云 Tingting | 主用不可用时 | 允许，但需记录 |
| L2 | macOS Tingting | 无阿里云凭证/服务故障 | 默认不允许；需豁免并在文案/复盘说明 |

## 4. voice 配置结构

    "voice": {
      "primary": {"provider": "aliyun", "voice": "用户指定 voice id", "speech_rate": 0.95},
      "backup": {"provider": "aliyun", "voice": "tingting"},
      "last_resort": {"provider": "system-say", "voice": "Tingting", "allowed_for_final": false},
      "require_primary": true
    }

## 5. 必须记录

voice.json 至少写：

- provider / voice / fallback_level；
- fallback_used / fallback_reason；
- gap_note（差距说明）；
- 音频 hash / 时长 / CPS。
